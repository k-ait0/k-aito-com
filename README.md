# DWZ R4 v16.4 — GitHub Pages 事前配置・セルフ診断

これは研究版の専用公開用ブランチです。リポジトリの通常サイトとは別ツリーで、index.html とこの説明だけを配置しています。

## 一度だけ必要な公開設定

1. k-ait0/k-aito-com の Settings > Pages を開く。
2. Pages が既に使用中なら **既存の設定を上書きしない**。その場合はこの手順を実行せず、独立リポジトリ／別ホストを用意する。
3. Pages が未使用の場合に限り、Build and deployment > Source を Deploy from a branch にし、Branch = dwz-pages-v16-3、Folder = /(root) を選び Save。
4. 配信を確認する。通常URL候補は https://k-ait0.github.io/k-aito-com/ 。URLの稼働はまだ確認していない。

**注意:** Pagesのブランチ公開でもGitHub内部のPagesビルドワークフローが発火し、GitHub Actionsを使う。現在のリポジトリはActions手動運用が基本方針なので、設定変更は管理者の明示操作で行う。リポジトリの main、Xserver の本番ページ、既存CIには今回一切触れない。

## 安全性

- 本ページは研究版、検索除外要請(noindex)のみでアクセス制御はない。
- 入力した資産額、保存した条件はサーバーに送信しない設計。CSPでネットワーク接続を禁止。
- 保存は明示操作時のみ、ブラウザの localStorage に暗号化せず保存される。共有端末や実額の入力は控える。
- GitHub Pagesのプロジェクト別パスは、同一ユーザーの別GitHub Pagesプロジェクトと同一originを共有しうる。センシティブ情報を保存する用途には推奨しない。専用カスタムドメイン＋追加のセキュリティ監査を推奨。
