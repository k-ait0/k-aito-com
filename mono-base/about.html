ABOUT

固定翼機・ロボット・宇宙開発を題材に、構想から設計・制作・検証までを記録する個人プロジェクトです。

PROJECT OVERVIEW

MONO BASEはKAITO内のエンジニアリング・制作拠点です。まずロボットアームや固定翼機など、実現可能なテーマから段階的に取り組みます。

DESIGN APPROACH

技術と設計方法を比較し、試作・検証へ進めます。未検証の性能値を開発実績として掲載しません。

DEVELOPMENT PATH

  1. CONCEPT — テーマと制作目標を整理
  2. DESIGN — 技術と設計方法を比較
  3. PROTOTYPE — 実制作と検証結果を記録

STATUS / CONCEPT — 現在の掲載内容は構想・検討段階です。実機完成や試験実施を意味しません。
