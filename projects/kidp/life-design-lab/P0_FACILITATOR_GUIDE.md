# KIDP-003 P0 — Facilitator Quick Guide

## 1. Open the review tool

`/projects/kidp/life-design-lab/test-review/`

This page is noindex and processes data only in the browser.

## 2. Give each participant a unique URL

P01:
`/projects/kidp/life-design-lab/prototype/?test=1&pid=P01`

Continue P02 ... P10.

## 3. Participant experience

Do not explain the intended result.

Say only:

「“ちょっとやってみたい？”を20回選ぶ試作品です。正解はないので、今の気分で触ってください。」

## 4. After the result appears

Ask the fixed post-test questions in P0_TEST_PLAN.md.

Enter:
- result resonance
- deep-dive category
- diagnosis misread
- first quote
- tester notes

Then press "CSV行をコピー".

## 5. Aggregate

Paste the header from P0_TEST_LOG_TEMPLATE.csv and participant rows into Test Review.

The tool calculates:
- M1 completion
- M2 resonance
- M3 deep-dive intent
- M4 diagnostic misread
- M5 average unclear cards
- decision

## 6. Rule

Do not change thresholds after seeing results.

P1 is not built until P0 returns P1 GO.
