# やりたいことルーレット v0.4（検証用）

LIFE DESIGN LAB マスター 005の初稿200件を利用した試作。カード内容はレビュー前です。
公開想定パス: /tools/want-roulette/ （XServer Staticへの同期設定と現地アクセス要確認）
このディレクトリ内だけで動作し、共通サイトのJavaScript/CSSを読み込みません。
入力データはブラウザの localStorage に保存します。異なるオリジンで使用した v0.3 の保存データは自動移行されません。
検索エンジン除外 (noindex) を設定しています。
service worker はこのディレクトリのみを対象とし、他のアプリのキャッシュは削除しません。
