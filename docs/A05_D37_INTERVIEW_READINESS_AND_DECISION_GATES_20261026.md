## 3. G2：提示設計と実行可能な割付表

`scripts/a05-research-assignment.mjs` は**参加者データを引数に受け取らない純粋関数**。入力はD-35/D-36候補と**1〜12の提示スロット番号**のみ。出力は次の通り。

| 割付 | 各スロット | 12スロット全体の設計上の件数 |
|---|---|---|
| 主要質問 | **30 IDにつき各1候補**、A01/B01/C01/D01/E01…の既存順 | 各IDについて12提示（途中中断がなければ） |
| BLOCK 7問 | 2候補A/Bをスロットごとに交互提示 | 各候補6回ずつ |
| REVISE 13問 | 旧D31/A/Bをスロットごとに3巡 | 各候補4回ずつ |
| TRIAL 10問 | D31候補を提示 | 各12回 |
| 深掘り用追問 | 3 P0＋1 P1、主要提示とは別の候補文面を比較 | 4項目/人、48追問枠。対象20 IDは各2〜3枠 |
| E05独立形式C | E05-MとE05-Tを別々に回答 | すべてのスロットで提示。実施順は「30問の前」6枠／「後」6枠 |
| 研究回答 | **一切保存・採点しない** | 実施開始自体がG1承認待ち |

全12枠は研究計画上の**割付予定**であり、12人の募集完了や検証上の標本サイズ確保を意味しない。8〜11人で打ち切る場合、表の均等件数は保証されない。実際の提示数・中断数・案別の母数を集計する。スロット順序の生成は再現用の設計であり、参加者識別情報ではない。参加順を決める運用はG1の審査対象とする。

### 認知負荷を制限する

「30主要問＋4比較問＋E05独立2問」は**上限計画**であり、長時間の回答や全項目の理由説明を強制しない。面接の目安45〜75分。30問すべての読み上げに加えて詳細な自由回答を求めると負荷が高い可能性があるため、時間超過時には中断・分割し、主要30問や追問の欠損を許容する。集計では未提示／回答拒否／読解不能を別々に記録する。

### 事前決定と偏りの注意

- 案の選定や参加者ごとの提示方法を**当日の答えを見て変更しない**。
- 主要30問の質問ID順は現行版とのトレーサビリティのため固定するが、順序効果を排除したわけではない。
- 案Cを30問の前／後に置くのは**探索的な順序差確認**であり、6対6を統計的に比較して有意と断定しない。
- 主要提示後の追問には学習・記憶効果がある。追問の回答を初回提示と同等な独立サンプルとして数えない。
- この割付は研究計画ドラフトであり、実際に使用する前に質問候補コミットSHA、同意文書版と割付規則を固定する。

## 4. 記録形式と非識別集計の例（空の項目定義のみ）

| フィールド | 形式 | 注意 |
|---|---|---|
| slot | 1〜12 | 参加者の氏名や連絡先の代わりではない。対応表を公開しない |
| itemId / candidateCode | A01〜E06、D31/A/B | E05-Cの二つの独立項目は別コード |
| presentationRole | core / followup / independent-E05 | 比較回答を独立標本として扱わない |
| status | responded / skipped / not-presented / interrupted / withdrawn | 欠損の原因を区別 |
| response | 1〜7 / null（未回答は別） | 中立4と回答不能nullを混ぜない |
| comprehensionCode | intended / other-axis / unclear / context-dependent / not-assessed | 自由回答から推測で人格を評価しない |
| reasonForNeutral | both-important / neither-important / context-dependent / cannot-compare / not-asked | 4の意味を一つに決めつけない |

## 5. G3：設問の意思決定ルーブリック

| 暫定編集判定 | 状態 | 必要な根拠 |
|---|---|---|
| **KEEP-CANDIDATE** | 設問を予備調査用の候補として維持 | 選択肢の読解が意図に概ね沿い、質問の対称性・回答可能性・他軸との区別が面接記録から説明可能 |
| **REWORD** | 文面再改稿を要求 | 語句の曖昧さ、社会的望ましさ、仮定の理解難、他項目との冗長性の具体例がある |
| **RETHINK-AXIS** | 設問数または測定軸の設計から戻す | 二極性が成立しない、Eの比較量が解釈者ごとに変わる、B/Cの両立を中立4だけでは説明できない |
| **STOP-ITEM** | 採点への採用を止める | 適用不能・強い不快・他軸との混同等が解消できない |
| **INCONCLUSIVE** | 判断保留 | 実施不足、適用条件の偏り、回答理由が不足、順序効果が切り分けられない |

**集計率のみで自動的に「合格」扱いしない**。面接は問題発見を目的とし、小標本の数を心理尺度の信頼性係数・統計的有意差に読み替えない。7 BLOCKと13 REVISEは、編集会議で根拠を明記して個別承認するまで元の状態を維持する。

| 案 | 内容 | 条件 |
