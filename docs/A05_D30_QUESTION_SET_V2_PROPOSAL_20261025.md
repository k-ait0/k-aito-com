## 設計判断

- **初期公開時の説明**：「価値観の傾向を考えるための自己理解ツール」であり、心理検査・適性判定ではない。
- **A〜Dの4軸**：現状の16タイプの表示互換を維持するため、まず設問の文脈分散と中立性を優先する。ただし自律とつながり、現在と将来は両立可能であり、真の一軸性は検証が必要。
- **E軸**：タイプ名や経済能力の優劣に直結させず、本人の条件に依存する補助的な志向として扱う。金額と時間の固定交換比率は撤廃する方向。
- **回答形式**：7段階の左右比較は当面維持するが、「どちらも大切／状況による」が表現しにくい問題をユーザーテストする。4の中立回答は欠損ではない。
- **比較可能性**：設問変更後の回答は別質問セット版として保存し、旧版と同じスコア尺度で直接比較しない。旧版は再採点しない。

## v2 採用ゲート

1. 30問の編集レビュー：年齢・家族構成・職業・収入による回答不能や誘導表現を洗い出す。
2. 各軸の概念定義と対立構造の妥当性を確認。両立する概念は独立軸化も検討。
3. 認知インタビュー：質問文の理解・中立回答・回答理由を確認。
4. 小規模予備調査：欠損率、回答時間、天井床効果、左右位置の偏り、再検査安定性を評価。
5. 質問セットの新バージョン・新ハッシュ・スコア比較禁止ルールを仕様に明記。
6. レビュー承認後にのみv2コードを作成。現行版の無断書き換えはしない。
