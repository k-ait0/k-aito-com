## 1. 正式に採用した決定

1. **12資産クラスと補助データ6区分を維持。** 補助区分は内部では8系列に分かれる。各資産クラスを必ず同時保有するという意味ではない。
2. **原則60年の連続月次履歴**を標準目標とする。基準の目安は1966年以降。既存Shillerの1980年開始は旧研究用データ取得範囲であり、将来の標準上限ではない。
3. 30年間の取り崩しを検証する際には、30年を**実測・欠損なし**で完走できる開始月数を品質指標とし、単純な年数だけで「長期分析可能」と判断しない。必要な全資産・為替・インフレ系列の共通期間を求める。
4. 60年分が存在しない資産（東証REIT等）は**取得できた履歴だけで検証**し、過去に存在しなかった価格を架空で埋めない。代理系列は別枠「Proxy Research」と明示し、正式のObserved Historyには混在させない。
5. **取得元を固定**する。別データ提供者へのサイレント切替・FRED経由での第三者権利回避・前月値による欠損埋め・価格指数を配当込み指数と偽ることを禁止する。取得元変更には理由、旧新系列差分、利用権利、QAと承認を記録したSOURCE_CHANGE_ADRが必要。
6. **商用サイトでの利用条件を最優先。** 商用処理、一般サイト表示、集計・グラフの配信、原データCSV再配布は別々に審査。許諾未確認の第三者指数をFINOWA／Analyticsに同梱・配布しない。
7. FINOWA（C案）は金融教育向け簡易モード、Analytics（B案）は詳細な過去市場分析・資産配分・ストレス・月次台帳・監査機能。共通計算／データ変換層を用いる設計方針を維持する。

## 3. 開発状況・未了事項を保存

| 項目 | 決定時点の実態 |
|---|---|
| 既存Shiller研究データ | 1980-01〜2023-06の522か月を復元。価格・年率換算配当・米国CPI。USD建て概算配当込みリターンであり公式S&P500 TRではない |
| 研究用ローリング計算 | 521月次リターン、30年を完走できる開始月162件（保有済み研究データの実計算） |
| 60年履歴の目安 | 1966-01〜2026-10の水準データが連続すれば、30年間を完走できる理論上限370開始月。**実際に取得した件数ではない** |
| Fedドル円 | 2026年秋の公式限定スナップショット28日分あり。1971年からの長期履歴は公式ソースに存在するが全件取得未了 |
| Fed取得チャネル変更 | 同じFederal Reserve BoardのDDP長期系列利用は**ADR-0001 DRAFT（未承認）**。現行の固定元を自動変更しない |
| 日本・米国CPI | 60年規模の公的系列候補を確認。長期実データ取得・統合QAは未了 |
| 世界銀行商品 | 1960年以降の長期系列が候補。個別列・第三者権利確認、長期ファイル取得は未了 |
| 日本株／債券／REIT等 | 正式な指数TRと商用サイト配信権を別に確認する必要がある。J-REITは2003年起点で30年分析不可 |
| 公開・本番 | Analytics、FINOWAへのデータ公開は**未承認**。DWZ PR #70と本番環境に変更を加えない |

時系列の長さは、配当込み総収益・外貨円換算・日本CPIの定義が揃うことを保証しない。**欠損月をゼロ収益と置かない**。観測期間が完走しない開始月は失敗率の分母から除外し、その数を表示する。過去実績の成功割合を将来の確率と呼ばない。
