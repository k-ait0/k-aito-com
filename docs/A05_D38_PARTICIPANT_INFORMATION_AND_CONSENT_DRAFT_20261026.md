> **内容**：複数の価値観に関する約30問の表現を読み、その意味や回答しやすさをうかがいます。面接者から追加の文言を示す場合があります。お金と時間の設問は別の形式も試します。所要時間の想定は約45〜75分ですが、疲れた場合は途中で休止・終了できます。

>
> **保存と利用**：個人が推測される回答は公開GitHub・PR・ウェブサイトには掲載しません。利用目的は質問の改善に限り、公開するとしても個人を識別しないよう配慮した集計結果に限ります。保存先・閲覧担当者・保存期間は募集時に承認済みの説明書で明示します。**現状は未確定のため、募集しません。**
>
> **撤回・削除**：個別データを識別できる間の撤回・削除依頼窓口と方法、集計後の取り消しが難しくなる時点について、募集前にお知らせします。調査途中でもやめられます。
>
> **連絡先**：〔研究責任者と問い合わせ・撤回窓口を確定後に記入。現在は未設定〕
>
> **調査の承認情報**：〔承認責任者、文書版、保管先、保持・削除期間、凍結した質問候補の識別子を確定後に記入〕

## 2. インタビュー開始時の同意確認案（実行前に承認が必要）

各項目は実施前に実際の参加者へ説明し、**記録が必要なら承認された私的保管領域にのみ保存**する。公開GitHubのチェック欄に参加者の同意情報を書き込まない。

- [ ] 調査が診断・評価ではなく設問の理解度を確かめるためと理解した。
- [ ] 任意参加・質問スキップ・途中中止・不利益のないことを理解した。
- [ ] 使用目的、記録内容、閲覧者、保存先、保存期間、問い合わせ先の説明を受けた。
- [ ] データ撤回の方法と、集計後に個別撤回できない可能性を理解した。
- [ ] **設問への回答や発言要約を記録してよいか**（はい／いいえ）。いいえの場合、記録せず実施しないか、別の記録不要の方法を検討する。
- [ ] **録音への追加同意**（実施しない／希望者のみ同意）。デフォルトは録音しない。
- [ ] **録画・画面共有への追加同意**（実施しない／別途明示同意）。デフォルトは実施しない。
- [ ] **募集・追跡のための連絡先を記録するか**（不要／必要な場合のみ用途と期間を別に説明）。回答データとは分離。

**単なる質問への回答や参加をもって全用途の同意があったとみなさない。** 参加者から否定・撤回があれば中止する。18歳未満を対象に含める場合は別途の要件審査が必要で、現段階では募集対象外とする提案。
