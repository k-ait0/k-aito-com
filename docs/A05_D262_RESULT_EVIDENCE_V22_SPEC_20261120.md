## 結果画面の4軸パラメーター

| 項目 | 表示 | 何を意味しないか |
|---|---|---|
| 参考方向 | 安定／変化などの左右方向、または保留 | 心理学的な確定診断 |
| 根拠の出所 | 30問の参考判定／Y/N補完の暫定方向／保留 | Y/Nを7段階得点へ換算した数値 |
| 研究用参考位置 | 7段階の平均加重得点 `ratio ∈ [-1,+1]` を中央0の左右対称トラックに置く | 偏差値、信頼度、タイプの確率、人口比率 |
| 情報の内訳 | 方向回答、4の中間、判断できない、当てはまらないを各7問中の件数で表示 | 7段階中間4とスキップの同一視 |
| タイプ根拠 | 30問方向採用軸数／Y/N暫定補完軸数／未確定軸数（合計4） | 単独タイプの正答率や確信度 |

数値の旧仕様：`scoreAnswer(x)=sign((x-4)/3)*abs((x-4)/3)^1.5`、`ratio=sum(scoreAnswer(x))/validCount`。旧表示の`width=50+50*ratio`は棒の塗り幅を割合と誤認しやすいため廃止。新しいマーカーの横位置は`left=50*(ratio+1)%`。線の中央が0で、左右の同一の単位系であることを見せる。

### 状態を混ぜない

- **全スキップ**：有効回答0、トラックのマーカー非表示、`回答がなく算出不可`。
- **全て中間4**：有効回答あり・方向回答0、マーカー非表示、`中間4のみ`。全スキップとは明確に区別。
- **左右が相殺**：方向回答があり、加重点数の合計は0。マーカーは中央に描くが、`方向回答が相殺`と表示し、単なる中間回答と同一視しない。
- **7段階が境界・設問除外に敏感**：参考位置マーカーは灰色系とし、**候補判定で採用されていない**ことを明示。
- **Y/Nで初めて方向を補完**：`Y/Nによる暫定方向`を別テキストに示す。30問の得点を変更しない。7段階が方向回答0の場合、Y/Nで方向が決まっても数値マーカーを生成しない。
- **4軸が30問でそれぞれ採用**：`30問の参考方向 4軸／Y/N暫定補完 0軸／保留 0軸`。これは分類根拠の数であり**信頼度のパーセンテージではない**。
