## 4モチーフの構図・画風判断

1. **世界樹**：根・幹・樹冠、長期的に育つ世界を表現できている。ペガサス等と同じ顔アップ比率へ寄せない。縦長カードの上下余白は**画像外UIで吸収**するか、樹冠を失わない別構図を制作する。
2. **ペガサス**：全翼を保護した構図は良いが小画面で主役が小さくなる。縮小サムネイルで馬と翼が識別できるか確認し、必要な場合は馬体を拡大した**別原画**を制作する。単純なcoverクロップで翼端を切らない。
3. **鴉天狗**：v34が安全余白と全身確認の観点で優先。ただしv32の翼のダイナミズムを破棄しない。ユーザーの美術評価を得るまで採否を固定しない。
4. **カーバンクル**：v33がv28より現行4作の重厚な神話表現に合う。青い額の宝石を識別特徴として維持。羽根状の耳・尾、彩度、特定IPの意匠に似ていないかの確認が必要。
5. **全体**：明暗、色温度、主役の画面占有率にかなり差が残る。青金の共通色への一律再着色は避け、R/G/B/Yを可変UI枠線として適用し各色で目視評価する。**色をキャラ属性に固定しない**。

## 残り12種類へ展開するための暫定ゲート
1. 正式採用16枠に含まれる名称・IDに厳密一致し、1枚1モチーフ。別キャラのポスター混入、架空の進捗表示、固定RGBY属性は不採用。
2. 原画に診断スコア、タイトル、フレーム、E軸、RGBY UIパーツを焼き込まない。
3. 「神話・伝承のD系コンセプトアート」を共通トーンとするが、自然物/飛翔する幻獣/人物型/小型幻獣それぞれの識別特徴を優先。**固定の被写体占有率や一律縦横比を合格条件にしない。**
4. 主要特徴に欠けがないことを全体表示・スマホ縮小・7%セーフゾーンで確認。描写の重要な部分が収まらない場合は再制作。表示は`object-fit:contain`。
5. 元画像・軽量表示用画像のファイルハッシュ、形式、サイズを管理。実A05の白基調結果画面への表示、RGBY全4色とE補助を別UIで確認。
6. 画像の出自・権利・独自造形、実ブラウザ、Safari/VoiceOver、ユーザーの美術承認を分離して記録。**形式検査や表示QAを美術承認と混同しない。**
