# A05 D-173｜Tier 1認知面接の実施・採否判断プロトコル（未実施）

**2026-11-11／研究専用**。主4軸16タイプ、銀行50問（A〜D各12＋E2）、一回30問（A〜D各7＋E2）を変更しない。今回の4課題は正式な採点質問ではない。

## 目的

D-164で整理した**優先10＋条件付き6＝16候補**が実際の生活価値観を測るかは未証明である。D-165の**未充足32枠**を、そのまま書き足して埋めない。最初にD-171のTier 1四課題に絞って、**設問の意味理解・条件の交絡・同義性・二極の両立**を対照質問と比較する。

## 調査方法と情報の取り扱い

面接の目安は各ケースについて**回答者5～8人程度の探索的な認知面接**。この人数はあくまで解釈の不一致を発見する実務上の小規模試行であって、信頼性係数や因子構造・母集団比率の推定に足る標本ではない。対象者の背景が極端に偏らないよう、居住形態・就労有無・家族構成などの経験差を考慮して募集するが、本人を特定する属性は収集しない。参加者に研究目的と任意性を説明し、途中終了を認める。

質問の順序は可能なら参加者ごとに「比較先→試作」「試作→比較先」を入れ替える。**最初に軸の理論を説明して回答を誘導しない。** 問題文の意味を本人の言葉で言い直してもらい、左右の選択理由、回答しづらい条件、両方成り立つか、他軸の能力や義務で決めていないかを記録する。

回答とメモは[オフライン画面D-170](../research/a05/d170-eleven-hypotheses-offline-cognitive-review.html)に入力し、回答終了後に**手動でJSONを保存**する。自動送信・自動保存はない。個人名や連絡先等を書かない。再読み込みは同じJSONファイルから行える。

今回改修した回答欄は、**中立／両方成り立つ／どちらも成り立たない**を分離した。過去の旧版`middle`値は区別不能なので、再確認しない限り分析では`旧記録・解釈不能`として扱う。

## Tier 1で質問する全文と判断条件

### A-G2｜生活に節目があるかどうかは『安定／変化』とは別の条件効果か

**比較先（A04）**：家事や用事を行う時間と負担が同じなら、普段の進め方はどちらを好みますか？

- 左：慣れた手順を基本として必要なところを整える
- 右：手順全体を別の組み立て方に変える

**試作案**：年度の区切りがあり、生活の便利さ・負担・必要な活動は今と同じだとします。次の一年の暮らしの基本をどうしたいですか？

- 左：現在の暮らしの基本を引き継ぎ、必要な部分を整える
- 右：暮らしの基本を別の形に組み立て直す

**観察すること**：同じ生活基盤を扱った場合に節目だけが選択理由なら、独立した得点用質問系統としては不採用

**処理方針**：A04と同義なら統合／節目効果なら非採点条件比較を継続

**回答後の追問**：

- それぞれ何を比較している問いだと解釈しましたか。
- 二つの問いで回答が異なった場合、その理由は何ですか。
- 回答理由に生活条件・金銭・義務・経験・能力などが含まれましたか。
- 左右の選択肢が両方当てはまる、またはどちらも当てはまらないことはありますか。

### B-G1｜自己決定を重視しながら、他者との相談や情報共有も高く望む人がいるか

**比較先（B-FU01）**：大切な人と二つの選択肢の希望が異なり、どちらでも負担が同じなら、何をより重視しますか？

- 左：話し合いを踏まえて自分が望む方を選ぶこと
- 右：話し合って双方が納得できる方を選ぶこと

**試作案**：重要な個人の選択について、次の二つの考えにそれぞれどの程度当てはまるかを独立に答えてください。

次の二つは**それぞれ独立して1～7**で回答する。両方とも高い回答を禁止しない。

- 重要な選択では、他者の意見を聞いた後でも、自分の考えを最終的な判断基準にしたい
- 重要な選択では、最終的に自分で決める場合も、身近な人と考えを共有してから決めたい

**観察すること**：独立評定が両方高い回答が観察された場合、現行の二極強制設問が回答者の価値観を単純化していないか検討する。ただし頻度や因子の分離は少数例で判定しない

**処理方針**：この2評定をBの二極得点へ直接加えない／設問分離の妥当性は別工程

**回答後の追問**：

- それぞれ何を比較している問いだと解釈しましたか。
- 二つの問いで回答が異なった場合、その理由は何ですか。
- 回答理由に生活条件・金銭・義務・経験・能力などが含まれましたか。
- 左右の選択肢が両方当てはまる、またはどちらも当てはまらないことはありますか。

### C-G1｜自由時間の配分と自由裁量予算の用途の違いは価値観か、所得余力・E軸か

**比較先（C01）**：今週自由に使える同じ時間を、将来と現在のどちらへ優先的に使いたいですか？

### D-G1｜分野を跨ぐ幅と、同一分野内の隣接テーマの幅を人が異なる価値判断として捉えるか

**比較先（D02）**：関心がある分野を同じ時間で学べる場合、どちらをより好みますか？

## データ検証と簡易集計

入力JSONの形式・11ケースID・回答コードを検査するため、`node scripts/a05-d170-research-aggregate.cjs session01.json session02.json` をローカルで実行する。**実際の参加者情報をGitHubへコミットしたり、第三者へ共有したりしないこと。**

この集計は件数と主な理由コードのみに限定し、回答者が記した自由記述を出力しない。回答が複数ファイルにまたがる場合の本人重複は自動判別できない。「二つとも高い」の件数が集計されても、それだけで新尺度を確立したとは解釈しない。意味の確認は研究担当者が匿名化された自由記述の原本を読んで行う。

## 採否の判定表

| 事象 | 次の処理 | 採点への昇格 |
|---|---|---|
| 何を聞かれているか説明できない／非該当が多い | 文面再設計 | 不可 |
| 二問とも同じ意味と理解され、同じ価値理由で答える | 一方を代替文面として保管し統合 | 不可 |
| 回答差が費用・所有権・勤務条件・能力・道徳規範による | 条件比較の研究へ戻す | 不可 |
| 両極が同時に肯定される（B） | 独立評定の方法をさらに検討 | 今回は不可 |
| 説明可能な価値関連の差分と公平な選択肢が確認できる | 認知面接を広げ、項目分析を計画 | **自動では不可** |
| 回答者数が極小、理由が曖昧、判断が割れる | 保留・反例を追加 | 不可 |
