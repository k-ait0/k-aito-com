## 採用した当面の方針

1. **設問ごとの重みは等しく1.0**とする。各回答を1〜7から−3〜＋3へ変換して集計する。
2. 50問候補バンクを維持し、30問抽出（A・B・C・D各7問＋補助E2問）を基準構成とする。
3. 16タイプはA〜Dの4軸で分類する。Eは現段階では補助項目とし、16タイプの分類には使わない。
4. 1問が複数軸に関連する可能性があっても、**現在は主軸以外へ加点しない**。
5. 現行の均等配点モデルを比較の基準版として保ち、後日の加重方式と区別する。
6. D219 GitHub Pagesの分類は**試作の参考表示**であり、正式に検証済みの心理測定法ではない。

## 将来の検討案：他軸にもまたがる設問への重み

質問が属する主軸とは別に、意味的に関係する副軸候補を設問メタデータとして記録し、後日、実回答データで副軸への加重を検討する。

例：A主軸に1.0、B副軸に0.25を加える案は**説明用の仮置きであり未採用**。「関連している」ことと「副軸の得点に加えるべき」ことを混同しない。質問の左右と副軸の左右の方向関係を確認する必要がある。

検討するメタデータ案（**今回はスキーマ・質問データの変更なし**）：
- `primary_axis`：主軸
- `secondary_axis_candidates`：候補となる副軸と符号・理由
- `semantic_overlap_flags`：意味的重複、二重計上への注意点
- `review_state`：未審査／検証中／採用／却下
- `weight_model_version`：重みモデルの版

## 加重方式へ移行するための条件

- 主軸が正しいかを先に確認する。誤分類を他軸加重で隠さない。
- 設問重複による事実上の二重加点と、軸間の測定対象の混同を調べる。
- 各軸で質問数・重み総量が違っても偏らないよう**軸単位で正規化**する。
- 実回答を用いて、均等配点モデルと加重モデルの安定性・判別性・解釈可能性を比較する。
- 重みの数値・推定方法・正規化式・受入基準・必要サンプル数は**未確定**。重みづけを行う実装変更には別途レビューが必要。
- 採点方式を変更するときは**バージョンを分け、過去の保存済み結果を自動再計算しない**。
- 現在の診断結果は現行版として保つ。

## 別件：拮抗した結果のUI（2026-11-15に確認された問題）

現在のD219では軸の合計値が0、または有効回答が不足すると分類を保留し、「もう一度診断する」以外の次の行動がない。この操作体験は、価値観の拮抗を診断の失敗のように扱うため改善課題とする。

**未採用の改善候補**：4軸の傾向を必ず表示し、境界に近い場合は近接する複数タイプを示す。利用者が希望するときだけ、未出題の50問バンクの設問から該当軸に追加質問して再評価する。ただし単に多数決で結果を強制せず、曖昧な場合は保留や複合傾向を尊重する。質問追加数・抽出条件・確信度閾値・UXの最終仕様は別途決める。
