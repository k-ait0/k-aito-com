## 4. 実際に比較するための研究手順

1. 既存二極（B-FU01/B-FU04、C-FU14/C-FU15、E01/E02）と改稿した独立6案を**研究セッション内だけで比較**。既存の採点エンジンへ加算しない。E旧2問は保留のため研究素材としてのみ使用。
2. 認知面接の最初の問いは「この質問を自分の言葉で説明してください」「何を想定しましたか」「答えにくい条件はありますか」「別の状況なら変わりますか」。仕事・家族・年齢・所得の前提を勝手に追加しない。
3. 両方を5にした人へは、**同時に大切だが衝突したらどう決めるか**を別途確認。両方1の人は無関心なのか、適用機会がないだけか区別。欠測・非該当・中点を別記録。
4. 同一回答者に二極・独立の両方式を示す場合は**順序を入れ替える**。質問の類似による回答誘導を監視。形式差だけではなく測定概念差を考慮。
5. まず設問を読んで理解できるか小規模認知面接（目安8〜12人）、その後に多様な回答者を対象とするパイロット。8〜12人は**編集用の目安**であり、因子分析・信頼性係数・妥当性を証明する標本数ではない。
6. A/Dは新規質問を量産する前に、旧「要改稿」群から軸外混入を除いて再編集。A4・D2という**出題可能枠の不足**は残る。差替えで不足を解消した場合も、正式認定ゼロから自動加算しない。
7. 16タイプ表示の条件と、自己理解向けの「独立重視度のプロフィール」は**別々の受入基準**で評価する。
