## 1. プロジェクトの目的と確定方針

A05は人生価値観に関する暫定16キャラクターを扱う企画。R1はそのキャラクターから**任意の2タイプを手動選択し、暫定設定上の共通点・違いを相互理解の対話素材として閲覧する**機能である。

S0で承認済みの不変条件：

- 表示趣旨：「2つのタイプの共通点と違いを見比べる」。R1は**一般的な相互理解ガイド**であり、恋愛・友情・職場など特定関係の予測器ではない。
- 16タイプは**科学的に検証された心理学的類型ではない**。現段階では暫定の編集キャラクターにすぎない。
- 相性点数、ランキング、優劣、「同型なら好相性」「全軸相違なら悪相性」、別れる確率、関係の成功予測を禁止。
- 診断の実回答からT01〜T16を自動割当しない。個人情報、実回答の保存、追跡分析をR1へ追加しない。
- 暫定4軸A/B/C/Dを表示する設計。E軸は補助で分類・R1比較の4軸には含まない。
- B2の研究を優先するが、**B2-P**（本人と関係者の希望を意思決定で考慮する度合いの2尺度案）と、自己決定理論（SDT）の自律性・関係性欲求の充足度は別概念。B2の採用や新たな測定妥当性の立証は未完了。
- T01〜T16、RGBYグループ色、旧Q/S/T/C版、旧136組の意味・IDは**無断変更しない**。類型数16/32/8は単なる数学的組合せであり妥当性ではない。
- GitHub Actionsは原則使わない。ローカルNode・ブラウザQAを優先する。
- 本番へのマージ・デプロイ・研究参加者募集・実ユーザー回答収集は、所定の人手レビューと最終承認がない限り実施しない。
