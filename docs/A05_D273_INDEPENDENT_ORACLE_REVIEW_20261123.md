## 検算表と数学的根拠

### 1. 1.5乗の7段階の固定期待値

1、2、3、4、5、6、7に対してそれぞれ
-1、-sqrt(8/27)、-sqrt(1/27)、0、sqrt(1/27)、sqrt(8/27)、1 と一致する必要がある。

- sqrt(1/27) ≈ 0.19245008972987526、sqrt(8/27) ≈ 0.5443310539518174。
- 各軸7件の同一回答で平均値を照合し、5と3は強度境界にちょうど一致するので「WEAK」、4は「TIE」とする。
- 境界は研究用・未較正の閾値であり、統計的信頼度ではない。

### 2. 30問と16タイプの真理値

- 全1：全軸左、T01のみ。
- 全7：全軸右、T16のみ。
- 全4：有効回答は各軸7件だが方向は不明、候補16タイプ。
- 全null：有効回答は各軸0件、候補16タイプ。4とnullは同じ回答ではない。
- A左・B右・C左・D右：T06。
- E軸2項目は分類に入らず、どの回答へ変えても4軸の採点・候補は不変。

### 3. 独立した「4件方向回答」「5/7中間＋スキップ」境界

- 方向回答2／7、中間5／7：D243判定保留、初回のY/N推奨あり。
- 方向回答3／7、中間4／7：D243判定保留、D243元ルールの5/7推奨はなし。
- 方向回答4／7、中間3／7：他の条件が満たされるとD243の方向判定可。
- **D255（後続の暫定分類版）にはD243元ルールと異なる、statusがclearでない軸へのY/N提示方針がある。後続版を古い仕様の同義として説明しない。**

### 4. 5回答・意味グループ・除外感応度の事前計算

- 4有効回答・4意味グループ：5有効回答に達しないため INSUFFICIENT。
- B軸で5つの異なる意味グループを採り、7・7・7・1・1を与えると、正規化合計は+1、平均+0.2。+1の1問を除くと合計0になり、itemFlipCount=3、familyFlipCount=3、FRAGILE、B軸方向保留。
- B軸で同じ意味グループに属する2問を7・7、残る独立5問を1・1・7・7・4にすると合計+2、平均2/7。単独回答除外では方向維持、同一意味グループの2問を除けば合計0。itemFlipCount=0、familyFlipCount=1、FRAGILE。

### 5. Y/Nの固定期待値

A/C/Dが右でBのみ未確定の状況では、
- B左YES・右NO：B左の暫定方向、T12。
- B左NO・右YES：B右の暫定方向、T16。
- YES/YES、NO/NO、UNSUREを含む初回ペア：B方向は未確定、T12/T16を保持。
- 初回両YESでも、別場面のペアがYES/NOなら、B左のY/N暫定方向としてT12。
- 初回YES/NO＋理由CONTEXT_DEPENDENTは別場面完了まで保留。別場面NO/YESなら矛盾があるため方向は決めない。
- 4軸とも未確定のとき、A左・B右・C左・D右の4ペア8問でT06。第9問は拒否。
- D243の元のsummarizeYNは回答によって候補タイプを変更しない。一方D255は暫定候補を絞る。**実装の不一致ではなく、版を跨いだ動作方針の変更として、仕様正本の明示が必要**。

### 6. D269におけるスキップ理由の伝達

B軸の2問をnull（UNKNOWNとNOT_APPLICABLE各1）、1問を中間4にして、総回答28／UNKNOWN1／NOT_APPLICABLE1、B軸有効回答5・中間1・スキップ2を確認。スキップ理由だけを交換しても採点は同じ。理由が不整合なら例外で拒否する。
