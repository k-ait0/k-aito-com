# A05 D-157｜A/B系統の統合・第4系統探索の審査結果

作成：2026-11-11。**編集研究用、正式採用ではない。** 既存の50問バンク、毎回30問（A〜D各7＋E2）、E軸2問、30問フォーム・抽出・採点・履歴、16タイプ表示、本番サイトは**変更しない**。

## 結論

現時点では**A-P4（生活サービス・用具）をA-P2（日常運用）へ、B-P3（共同資源）をB-P2（共同方針）へ統合する方向を編集上推奨**する。第4系統の代替案を設けるより、A/Bを当面それぞれ3つの観察場面で構想し、明確に異なる判断材料が見つかるまで4番目を保留した方がよい。

「3系統」を新たな心理尺度や確定した採点区分とみなさない。3系統の中に12問を無理に詰める行為は禁止。Bの自律・つながりの両立可能性は、系統分類と別に独立評定の比較研究で扱う。

## 1. 系統を統合する根拠

### 特に注意すべき2つの提案

- **A155-02（活動所属組織）**：住居や道具から離れた環境の継続・更新を問える可能性はある。しかし組織帰属意識、B軸の関係・合意、活動拠点A-P3との重複がある。**新しい第4系統として即採用しない**。
- **B155-01（意見が一致しているときの他者参加）**：重要な観察点だが『相談すること』と『自分で最終決定すること』は両立できる。二極7段階の採点質問へ加えると定義が揺らぐため、Bの独立評価を考える**非採点の比較研究用**に限定。
