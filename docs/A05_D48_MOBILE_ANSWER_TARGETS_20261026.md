# A05 D-48 — 狭いスマホの7段階回答を押しやすくする

**2026-10-26｜D48-001｜Draft PR内のUI品質改善。採点/質問内容/研究運用の変更なし。**

## 背景と修正

A05の既存7段階の数値回答ボタンは、広い画面では7列の横並びとして直感的だが、320〜400px級のスマホでは1ボタンの横幅が44px未満になる可能性があった。D-29/30の既存検証は**高さ44px以上と横スクロール無し**を確認していたが、**幅44px以上を未検証**だった。

今回はCSSのみ変更し、**幅440px以下で4個＋3個の二段配置**に変更。5番目を2列目に配置して下段3個を右側に寄せ、ボタン1〜7のDOM・タブ・読み上げ・数字キーの順序は維持した。通常の画面幅では従来どおり7列。400px以下の左右選択肢の縦積みレイアウトはそのまま維持する。

## 追加の実ブラウザ受入条件

既存 `scripts/qa_a05_browser.cjs` にD-48のChromeケースを1件追加し、320、375、390、400、420、440、480、768pxの各画面幅において：

- 数字ボタン7件が存在し、全件の描画済み**幅・高さが44px以上**であること
- 440px以下では2行、480px以上では1行に配置されること
- 本文全体が画面幅を超えて横スクロールしないこと

これは実際のモバイル実機テストの代替ではない。タップ精度や端末固有の文字拡大等の確認は別途必要。既存D-47の数字キーとD-45の質問レビュー・保存機能もそのまま検証する。
