## 1. この先行パイロットで確かめる問い

1. 7段階の「4（有効な中立回答）」と「判断できない・当てはまらない（スキップ）」の意味を参加者が区別し、意図どおりに選べるか。現行スキップの2語を1ボタンにまとめたラベルが紛らわしくないか。
2. Y/Nで左右の価値を**独立に**答えること、YES/YESとNO/NOが認められること、UNSUREはNOではないことを理解できるか。
3. 「4」やスキップの理由選択肢（`BOTH_STRONG`、`BOTH_WEAK`、`CONTEXT_DEPENDENT`、`BALANCED_MODERATE`、`WORDING_DIFFICULT`、`OTHER`、`PREFER_NOT`）が、本人の理由を過度に誘導せず表せるか。特にBOTH_STRONGとBALANCED_MODERATEの違い。
4. Y/Nが任意・得点外であること、途中終了しても参考結果へ戻れること、Y/N回答で16タイプ候補が変化しないことを参加者が理解しているか。
5. 30問の後に2問→条件付き最大2問/軸、全体8問の負担をどう感じるか。7段階の追加2〜4問との併用導線は**未較正**であり、機能が提示されても「精度向上」と説明しない。

## 3. 面接担当者の実施順

0. **実施前の必須事項**：研究目的、任意参加、中断可、記録項目、利用範囲、匿名化方法、保存期間・撤回方法・問い合わせ窓口を具体的に説明し、同意を記録する。保存期間・連絡方法が未決のまま実データを集めない。録音・画面収録は別の明示同意がなければしない。
1. 同意後に参加者自身の操作でD246を開く。原則として設問の意味や回答方針を説明せず30問を完了する。開始・終了時刻、操作上の停止、7段階の4/スキップの本人説明を端末外の匿名シートに記す。
2. 結果画面で「これは何を示していますか」「なぜY/Nを受ける／受けないと思いますか」と自由に聞く。Y/Nリンクが表示されなければ`NOT_OFFERED`。
3. Y/Nを自発的に開いた場合、回答前に本人の言葉で質問の意味を説明してもらう。回答後に「YES/YESやNO/NOはどういう意味ですか」「判断できないとNOはどう違いますか」と非誘導的に聞く。本人が選ばなかった回答を強制しない。
4. 中間・スキップ理由のプルダウンを見て、「この選択肢にない理由はありますか」を尋ね、選択理由を簡潔に記す。BOTH_STRONGとBALANCED_MODERATEに混乱があれば実例を聞く。選択肢を先に解説しない。
5. 本人が途中終了した場合、「なぜここで終えましたか」「参考結果に戻れると分かりましたか」を聞く。疲労や中断を責めない。
6. Y/Nが現れなかった人には、自然回答を保存・変更しない状態で、必要ならカード理解トラックCを任意提示。**トラックCで得た答えをY/N採点、実画面の出現率、UI完走率に混入しない**。
7. 終了後に「意味が不明だった文」「長い・繰り返しと感じた箇所」「途中でやめたかった場所」を自由に聞く。少なくとも端末種別と所要時間、途中停止、Y/N表示有無を匿名記録する。
8. 回答内容が失われるUIであるため、研究者が保存するのは明示同意を得た**最小限の匿名観察記録のみ**。無断で画面の回答やセッションを収集・再現しない。
