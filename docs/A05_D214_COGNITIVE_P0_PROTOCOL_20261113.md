## 実行用の研究フォーム

- HTMLは `research/a05/d210-research-template.html` と `scripts/a05-d210-build-offline-form.mjs` から生成する。
- 全50問モードでのみ3組の原文・左右選択肢・各回答値を再掲し、**同じ意味／異なる意味／判断不能** と自由記述の回答理由を収集する。
- 30問モードでは設問の片方が出題されない場合があるため、重点比較フォームを表示しない。
- B/Cの4つの独立評定も非採点として収集し、「両方高い」と「両方低い」の観察を可能にする。
- 同意後に回答する。入力は外部送信しない。明示的にJSONファイルを書き出す場合だけ手元に保存する。
- 読み込めるファイルは対応したバンクdigestと質問構成の研究データに限定。不正ID・不正尺度・過長コメントは拒否する。

## 研究データを読む際の条件

- **仮想回答はUI／計算の異常を発見するためのみ**。人間の心理傾向についての証拠としない。
- レビューで重複を否定するには、言い回しの差だけでなく、**異なる価値観に基づき異なる回答になる理由**が必要。本人の状況・能力・所得だけで差が出る場合は別構成概念と認めない。
- C35/C36の片方を差し替えるときは、既存50問の置換先ID・測る新しいファセット・全文・他設問との衝突を必ず記録する。
- C31/C32は研究対照。結果を利用して稀少性の影響を識別したうえで、最終の採点用50問に残すか判断する。
- Eは2問なので、回答者の好みの一時的な条件変化と安定した傾向を分けられない。人数が集まっても単純な平均だけで尺度成立としない。

## 最短の判断順序

1. この3組について、認知面接による説明を得る。
2. C35/C36が同義なら片方を差し替える。C31/C32は測る構成概念がC軸ではなく稀少性なら研究用へ移す。
3. B/Cの独立評定から相対選好と両方高い／両方低い状態の扱いを確認する。
4. それ以外の15組の優先比較を点検する。
5. 研究用50問を改稿し採点候補を固定してから、実回答を使った30問セット間の安定性検証へ進む。
