## 研究の仕様

| 項目 | 固定ルール |
|---|---|
| 初期資産 | **100,000 米ドル相当の数値単位**（日本円ではない） |
| 積立 / 年金 | 0 / 0 |
| 資産運用 | Shiller公開候補の株価・年率配当からの概算月次係数 `(P_t + D_t/12)/P_(t-1)` |
| 取り崩し率 | 初期資産の月0.25%、0.30%、0.50%、1.00% |
| タイミング | 月初取り崩し、残額をその月の概算係数で運用、月末残高を整数単位へ四捨五入 |
| 生活費モデルA | 初期の月額を毎月固定（名目固定） |
| 生活費モデルB | `基準額 × 米国CPI[t-2] / 米国CPI[start-2]`（2か月ラグの説明用近似） |
| 窓 | 10年=120か月、20年=240か月、30年=360か月 |
| 対象開始月 | 1980-03以降。CPIの2か月ラグを成立させ、両モデルの開始月を完全一致させる |
| 資金不足 | 要求取り崩し額が残高を超えた月を1度でも含む窓。残高はマイナスにしない |
| 結果の解釈 | 過去の重複した開始月の記述統計。将来の成功確率ではない |

**注意:** CPIの2か月ラグはリリース日を厳密に再現したものではない。月次平均株価と配当年率値も実際のファンドの執行価格や公式S&P500 TRではない。税金、売買手数料、為替、インフレヘッジ、ファンド費用、分配課税等は未反映。開始月で満額投資し資産形成するシミュレーションではなく、既に保有した資産の取り崩し経路を試算するもの。
