# K. Aito Analytics｜長期実績データ 60年標準計画 v0.5
**方針確定日：2026-11-11｜研究開発。12資産クラス・補助6区分を維持。**
**本書は取得・ライセンス・サイト公開の完了を意味しない。**

## 決定事項
- **標準目標：原則60年の連続した月次観測（目安1966年以降）**。既存1980年開始は旧研究データの切り取りであり、これを恒久的な取得開始年としない。
- **分析対象が30年であるなら、30年を完走できる開始月の数を品質指標にする。** 60年程度の実績があれば開始月の選択肢が増える。
- **60年に到達できない資産を架空の価格で埋めない。** 原系列の起点・終了月・連続性・データ定義（PR/TR/スポット/金利）を個別管理する。
- **リサーチ用・サイト用を分ける。** 権利未審査のShiller旧研究データやJPX/S&P/MSCI等の指数値をFINOWA/Analyticsに同梱・再配布しない。
- 取得先は `research/analytics/source_registry.v0.2.json` の固定元に従う。変更先候補を発見しても **SOURCE_CHANGE_ADR** がない限り自動切替しない。
- 現物スポット（World Bank）を保有商品のTR、国債利回りを債券TR、日経平均の価格指数をTOPIX配当込み指数の代替とは呼ばない。

## 30年の開始月数（すべて連続した月次価格水準があると仮定した**理論上限**）
- 1980-01〜2023-06：**522か月の水準 → 521月次リターン → 162開始月**
- 1966-01〜2026-10：**730か月の水準 → 729月次リターン → 370開始月**
- 1971-01〜2026-10：**670か月の水準 → 669月次リターン → 310開始月**
- 2003-04〜2026-10：**283か月の水準 → 282月次リターン → 0開始月**

複数資産のバックテストでは**必要系列の共通実績期間**を使う。最も短いシリーズが開始月数を制約する。必要な実際の欠損月があればその開始ウィンドウを無効とし、補完・直前値継承を行わない。計算対象外の開始時期を「失敗」と数えない。過去の成績を将来の確率と断定しない。

## 画面設計：3つの履歴モード
1. **Observed History**：正規の実測・公開系列で確認できた連続期間のみ。代理指標を混ぜない。
2. **Restricted Historical**：資産起点や長期不足に応じて短い履歴で比較。30年完走不能なら理由を表示。
3. **Proxy Research（別枠）**：例えばJ-REITの2003年前の不動産価格等を別系列で代用する場合は、厳密な過去実績として扱わず、出典・仮定・切替点・不確実性を表示。現在は未実装・未承認。
