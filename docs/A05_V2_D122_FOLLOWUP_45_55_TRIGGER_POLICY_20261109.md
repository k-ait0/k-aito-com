# A05 D-122｜詳細診断へ進む条件：軸別45〜55%（2026-11-09）

**製品方針として採択するのは「追加質問の案内条件」であり、心理測定学的な判定境界ではない。** D-120/D-121の適応型追加質問仕様を具体化する。研究用記録。v1本番・v2質問・採点・保存・レポートは変更しない。

## 決定内容

1. 共通30問（A〜Eの5軸×各6問）の後、各軸ごとに「50%を中心とした±5ポイント」を確認し、**45%以上55%以下（両端含む）の軸を追加質問の候補**とする。
2. **A/B/C/D**は16タイプの構成軸として、該当軸だけ個別の追加問題を案内する。**E**も同じ数値条件を使えるが、補助的な確認として扱い、16タイプの出力条件に連動させない。Eを案内する場合も利用者がスキップ可能。
3. 有効回答数が**4問未満**の軸は、数値が45〜55の外側に見える場合でも**欠測不足の追加確認候補**とする。判断不能と中立4は別々に保持する。
4. 軸によって出題内容・数・順序は異なり、Y/N・A/B・判断不能/非該当を用意。既存回答や追加回答を無校正で混ぜない。
5. **45〜55の範囲外＝確定タイプではない**。今回は「詳細診断をいつ案内するか」のUI運用条件であり、測定信頼性や真の分類確定を保証しない。詳細追加後も分類保留可能。

## 現行v2 engineとの数値の対応

現行のエンジンは1問の回答を `answer-4` の-3〜+3とし、`sum` と有効回答数 `n` から **`value = 100*sum/(3*n)`（-100〜+100）**を計算する（n=0のときvalue=null）。

UI上で50%中心の尺度にする場合は **`centeredPct=50 + 0.5*value = 50 + 50*sum/(3*n)`**。ここでの50%は回答方向の中央であり、「その方向に属する確率50%」ではない。

**基本トリガー**（n>=4）：`45 <= centeredPct && centeredPct <= 55`。丸められた表示値で境界判定しないため、実装では **`Math.abs(sum)*10 <= 3*n`** という整数比較にする（`|sum|/(3*n) <= 0.1`と同値）。

6問すべて有効なら `sum=-1,0,+1` だけが該当（それぞれ約47.22%,50%,52.78%）。`sum=±2`は約44.44%,55.56%で対象外。n=4・5でも同じ`sum=-1,0,+1`が対象。n<4は欠測の例外条件。

**注意**：現行v2の軸statusは別基準（`|sum|<=n`ならprovisionalなど）であり、今回の45〜55トリガーとは一致しない。`provisional`の全件に追加質問を出す設計ではない。

## 例

| 軸 | 表示例 | 追加の扱い |
|---|---:|---|
| A | 52% | 追加候補 |
| B | 72% | 追加なし |
| C | 48% | 追加候補 |
| D | 20% | 追加なし |
| E | 50% | 補助の追加候補（任意） |

上記はルールを示す表示例で、6問等重み7段階の実スコアとして全ての数値が厳密に出現するわけではない。

## 実装時の受入ケース

- n=6,sum=-1/0/+1 は追加対象、n=6,sum=-2/+2 は対象外。
- n=4,sum=-1/+1 は追加対象、n=4,sum=-2/+2 は対象外。
- n=3,sum=9 は有効回答不足として追加対象（スコアが中央から遠くても）。n=0,sum=0 も追加対象。
- 既存のEは16タイプの方向判定には含めない。
- 45〜55の外側でも単一タイプ名の科学的妥当性を推論しない。
- 追加質問の数・タイミング・反証質問・終了条件・本人スキップ・最終分類保留はD-120を踏襲。
