## 7. 次の採否ゲート

1. **旧原文と改稿案を同じものとして扱わない**。軸外となった元の質問は、別IDに書き換えても元の採点適格性が復活したことにはならない。
2. **同系統最大2問**を守るため、各衝突群について「元々の意味系統・回答理由・条件の違い」を1行ずつ記載する。単なる時期・場面の違いなら2問採らない。
3. **認知面接前に候補を絞る**。重複懸念が強い7問は対照の位置づけが有力で、実回答がない限り2問目を採点へ昇格しない。
4. **E01/E02は2問を維持**し、内容および二極/独立方式について別途評価。Eの問数は議論し直さない。
5. **採点・公開の変更は別の承認工程**とする。新版50問バンク全体の妥当性、7問ずつをランダム抽出した場合の比較可能性は、実回答者の項目分析まで保留。
