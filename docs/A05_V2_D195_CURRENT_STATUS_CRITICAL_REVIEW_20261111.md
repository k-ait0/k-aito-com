## 2. 研究成果の実質評価

- **良い点**：重複しそうな問いも早期削除せず、原案・言い換え・別場面と比較先を追跡できる。過去の除外案も再評価している。認知面接の入力・JSON・集計・ブラウザQAが存在し、再現性に配慮している。
- **弱点① 内容独立性**：D-190の「内容の可能性10仮系統」のうち6方向はD-184の先行有望6問と重なる。名称や表現が違うだけで新系統を数えてはいけない。
- **弱点② 概念の交絡**：Aの物品愛着・居住地・帰属、Bの意思決定と相談の両立、Cの金銭/E軸・休息・後悔、Dの能力・創作経験などが混ざる。
- **弱点③ 問文の仮定**：D-192の文字列フラグでは96問中67問に「同じ／等しい／変わらない」等の統制表現。実際の理解しやすさを調べず、仮定条件が多いほど良いと解釈しない。
- **弱点④ 検証結果の読み違い**：D-192の分類は研究者による編集判断、語句チェックはルールベース。**実回答者0、尺度の信頼性・妥当性が証明された問0**。形式上「99/99」「111/111」テスト合格でもここは解消しない。
- **弱点⑤ PR運用**：PR #76は**139ファイル・187コミット・追加約53,967行**。設問研究と本体コード変更が一つのPRに載り、レビュー・差戻し・マージ範囲の判断が難しい。今後は研究成果と製品コードのリリースゲートを明確に分けるべき。既存PRを勝手に分割・マージしない。
- **弱点⑥ 版と数え方の混同**：D-129の古いPoCには過去時点の「不足8」というフィクスチャがある一方、現在のD-164の編集上の不足は32。**資料の作成時点と採用基準が異なる**。単一の最新台帳を参照しないと進捗率が歪む。

## 3. 抽出方式の数学的問題（条件付き）

仮に各軸12問が**本当に別の6系統×各2問**だった場合、各軸7問を完全一様抽出した792通りについて、4系統のみ120通り（15.15%）、5系統480通り（60.61%）、6系統192通り（24.24%）。**1系統以上欠けるのは75.76%**。

D-193は「6系統から1問ずつ＋1系統から追加1問」の層化案を研究用に列挙。**各項目の周辺出現確率7/12は保ち、6系統の出題を保証**する。ただし**本当に異なる6系統×2問が成立した場合限定**、質問難度・採点等価性の検証ではない。抽出アルゴリズムはまだ本体へ導入していない。
