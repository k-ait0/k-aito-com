## 2. 外部AI提案の受入ゲート（順番固定）

| ゲート | 確認内容 | 失敗時の扱い |
|---|---|---|
| G0 根拠追跡 | 既存原文を実際に参照したか。引用した元ID、版、提案IDを確認 | 原本未参照として照合まで保留 |
| G1 意味重複 | 元30・現50・D121/125・旧候補の**選択場面、比較次元、回答が変わる条件**を対照。語句一致だけでは不十分 | `DUPLICATE`：追加数に含めず旧問の改稿案として扱う |
| G2 軸の純度 | 各軸の目的以外の社会性、能力、収入、環境制約、不安、成果の確実性、社交性などが左右で非対称に混ざらないか | `REWRITE`または`PROBE_ONLY` |
| G3 比較の均衡 | 左右で費用、時間、効果、責任、機会希少性、倫理的魅力を勝手に変えていないか | `REWRITE`。測るのが効果条件なら研究プローブへ |
| G4 回答可能性 | 就労、転居、同居、育児、所得水準を前提にせず多様な生活段階で解釈できるか。「非該当」「判断できない」を許すか | `REWRITE`または対象集団限定の研究用 |
| G5 新情報の証明可能性 | 既存近接問に同じ回答をした人が、新問だけでは異なる回答をし得る**具体的な反例・新条件**を記述できるか | 新情報が説明できなければ`DUPLICATE`または`HOLD` |
| G6 尺度構造 | B/Cの二極と独立重要度、Eの二極と独立2項目を混同していないか。Y/NのNoを反対極へ加点していないか | `STRUCTURE_RESEARCH`。既存スコアに加算禁止 |
| G7 人的確認 | 認知面接で「どう解釈したか」「どの前提で選んだか」を確認する質問が用意されているか | `COGNITIVE_TRIAL`以前へ進めない |

**区分の定義**：`DUPLICATE`（旧問との同義/近似・新設カウント禁止）、`REWRITE`（交絡除去が必要）、`PROBE_ONLY`（混入概念や理解度の確認のみ・非採点）、`STRUCTURE_RESEARCH`（二極/独立等の採点方式変更が前提）、`COGNITIVE_TRIAL`（人への試行が許される編集候補・未承認）、`HOLD`（保留）。**これらに「採用済み」は含まない。**

## 4. 外部AIから受け取る一行一候補レコード

`仮ID｜軸｜質問文の全文｜回答形式・全選択肢｜測る価値観｜比較した元ID（最低1件）｜旧問と違う回答が生じる条件｜交絡・誘導リスク｜B/C/E尺度方式との関係｜提案者の優先度｜審査区分（受領後に当方で付与）`

受領時は、本人が付与した「新規」「優良」のラベルを**無審査で引き継がない**。対応する旧IDが不明なら照合未完了と記録する。採点・コード・PR本体への自動反映を行わない。

## 5. 比較・意思決定順序

1. 外部AI提案とD-133原本を項目IDで比較し、`G0〜G6`で重複除外・尺度方式を分類。
2. 既存の「条件付き試行15件」を無条件に上回るとせず、**同じ旧問の改稿**と**本当に新しい判断場面**を別集計。
3. B/Cの構造（二極トレードオフか独立重要度か）、Eの参考表示方式を検討し、構造を跨ぐ得点変換はしない。
4. 軸別最大3件の編集優先候補を提案。該当なしも許す。対象ユーザーへの認知面接（目安8〜12人）を行い、解釈のずれを記録。
5. 固定30問の内容品質を先に確認。可変50問は項目の同等性とフォーム間比較可能性を別途確認できるまで研究段階に留める。
