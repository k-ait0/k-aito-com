両方ともRailwayの同じBasic認証を要求する。認証情報は環境変数にのみ置き、リポジトリには含めない。

## 今回実装した機能

- 入口は**診断を始める**、その後30問の7段階回答、最後に参考結果という3画面のみ
- D206編集バンク50問から、D208の条件を保ってA/B/C/D各7問＋E2問の**30問**を抽出
- 前の質問に戻って修正できる。「判断できない／当てはまらない」も選択可能
- 終了後に**16タイプの名称・概要（草案）**と4軸の回答傾向を表示
- 4軸のうち1軸でも有効回答5問未満、または正負合計0なら、タイプ表示を保留する
- 他の軸であっても得点の絶対値が小さい場合は境界に近いことを明示
- Eは参考項目2問でありタイプの判定に使用しない
- 簡易集計は各項目の回答1〜7から4を差し引く方式。これは**研究デモ専用で未検証の暫定ロジック**であり、D209のG1/G3/G4/G5完了や正式採点を意味しない
- 回答値と結果はページ内のメモリのみで処理。自動送信・Cookie/サーバー保存・結果の履歴登録なし
- リスタート時は新しい30問構成に切り替わる可能性がある
