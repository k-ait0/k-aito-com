## 4. 制作の再発防止ルール

1. 各生成開始時に**正本の対象IDを1件だけ**取り出す。画像自体が1モチーフ単独であり、RGBY/診断結果/制作進捗を描き込まない。
2. **生成直後に主題を照合**：山や月だけでなく、港は「静かな天然の入り江と小規模泊地」、大海は「開けた水平線」、月は「月という天体」という意味上の正しさまでチェック。対象が変わってしまった場合は一切の候補登録を行わない。
3. 一度の生成で対象が引きずられる場合は**その段階で止めて原因を分離**する。異なるモチーフへ名称を付け替えるなどして作品数を水増ししない。
4. 候補の画像バイト列・SHA-256・画像寸法をローカルレビューキットに記録し、GitHubの制作台帳へは元画像を公開せず**未承認ステータスだけ**登録。
5. 技術的な「画像を読み込めた」「HTMLが動作する」と、ユーザーによる「試作品合格」、本番用の最終承認を区別。
