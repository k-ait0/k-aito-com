### 配信環境での制約

`http://127.0.0.1:18765/reflection-d99.html` を実HTTPサーバーで配信し、Chromiumで `page.goto` を試したが `net::ERR_BLOCKED_BY_ADMINISTRATOR` により遮断。**通常URL型のE2Eは未合格**。HTML直接注入QAはこれを代替できる部分に限定する。
