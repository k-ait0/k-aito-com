## 5. Deep Researchの受入プロトコル

文献を採用候補にする場合、1原典ごとにLIT-xxxのIDを発行し、最低限、次の項目を記録する。

1. 原題、著者、年、DOIまたはHTTPSの原典URL、原典への到達可否。
2. 研究デザイン（メタ分析／縦断／二者データAPIM／横断／実験等）、サンプルと母集団、国・文化、恋愛・友情・職場・家族のどの文脈か。
3. どの構成概念をどの尺度で測定したか。**A05のA/B/C/D/Eと同じ構成概念と仮定しない**。
4. 効果量、信頼区間・標準誤差等の不確実性、未報告の場合の理由。効果量の欠測をゼロと解釈しない。
5. 交絡、選択バイアス、逆因果、一般化可能性、研究者が述べる限界。
6. 原典確認者、照合日、編集・心理測定レビューの承認者、主張できる範囲、反証となる研究。

自動要約や引用候補だけでは「レビュー完了」にしない。原典の確認と人手承認を別途必要とする。一般研究のIDを136組に機械的に付与して、個別相性の裏付けにしない。

## 6. 日本語コピーの安全基準

| 禁止する断定・誘導 | 編集プレビューで許容する言い方 |
|---|---|
| 「T02とT11は相性が悪い」 | 「現行の設定上、重視する方向のラベルに違いがあります。実際の希望を確認してみましょう」 |
| 「同タイプだから価値観が一致する」 | 「ラベルは共通しますが、具体的な優先順位まで同じとは限りません」 |
| 「B軸が逆なので自律と人間関係が衝突する」 | 「一人で決めたいことと相談したいことは、それぞれ何ですか？」 |
| 「違いがある二人は補完し合える」 | 「違いが新しい視点につながるか、話し合ってみる余地があります（編集上の仮説）」 |
| 「この組合せは長続きする／離婚しやすい」 | **結果予測は表示しない** |
| 「相性92点、Sランク」 | **点数・順位は表示しない** |

コピー審査では、属性の固定化、価値判断、相手への不当な説得材料、責任転嫁、強制的な共有を避ける。話し合いの問いは回答者の意思を尊重し、関係を継続すべきだという圧力をかけない。
