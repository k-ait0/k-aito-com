**対象：Ver.2.1比較研究用プレビューのみ。ユーザー承認のVer.1、技術合格したVer.2、D242通常版は変更しない。**

## 対象と設計

1. **スキップ理由を分離**：最初の30問の「判断できない」(UNKNOWN)と「当てはまらない」(NOT_APPLICABLE)を別の回答操作として記録。7段階の採点には両方とも`null`として渡す。回答理由はセッション内の`skipReasons`辞書だけで保持し、外部送信・保存はしない。戻って7段階回答に訂正すると理由も消去する。結果は有効回答／判断不可／非該当を別集計。D255の採点・分類基準は変更しない。
2. **結果画面の情報を3タブに分割**：「タイプ概要」「4軸の分析」「詳しい説明」。結果の再計算はタブ切替に依存せず、Y/N追加の動線と再診断はタブ外に残す。研究用暫定分類の注記は維持。
3. **7段階の説明を明確化**：左右の価値観に対して1は左寄り、4は中間、7は右寄り。4はスキップとは区別して有効な中間回答として採点処理する。選択ボタンに説明を付ける。
4. **追加Y/Nの進捗を全体通算で可視化**：独立した最大8問枠に対する`回答済み件数/上限8問`と進捗バー。現在の2問組での位置は別に表示。任意で途中終了でき、上限8が必ず出題される保証はないことを区別する。
5. **スマホのノースクロール回答動線維持**：Ver.2の`100dvh`・長文時の安全なスクロールフォールバックを継承。2つのスキップ理由を横並びで配置。
