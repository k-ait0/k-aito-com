## 実施した隔離表示QA
Chromiumのインメモリ`page.set_content()`で生成HTMLをロードし、画像をdata URIにした状態で検査（**実サイト／保存済みファイルをブラウザで直接開く試験ではない**）。

| 条件 | 結果 |
|---|---|
| PC幅1280px | 画像2件ロード、カード2件、横はみ出しなし |
| モバイル幅390px | 上記と同様、レイアウト横はみ出しなし |
| 小幅320px | 上記と同様、レイアウト横はみ出しなし |
| R枠線への切替 | CSS border色=rgb(255,59,92) |
| E軸=time切替 | 補助ラベル「時間的自由」 |
| スマホカード表示切替 | `mobile`状態反映、横はみ出しなし |

`file://`および`127.0.0.1`のページナビゲーションは、この作業環境では管理者ポリシーにより拒否されたため、`page.set_content()`で検証した。したがって本番A05での画像配信、相対パス、IndexedDB、Safari、VoiceOverは**未検証**。

## 制作上の重要事項
- **原画とUIを混ぜない**：画像にはロゴ、RGBY、スコア、タイプ名、説明文、テスト状況を描き込まない。
- **24px単独Tier1採用禁止**：名称併記の116px初稿を現状維持。人間の小サイズ視認性テストが必要。
- **正式原画の合格条件**：被写体の四肢・翼端・尾の完全収まり、文字や枠なし、PC/スマホで使える余白、自然物／神話キャラ全体で一貫した描写。原画の色コードを16×RGBYへ増幅しない。
- 128表示は16キャラ×RGBY4×E2の表示組合せであり、人格数ではない。
