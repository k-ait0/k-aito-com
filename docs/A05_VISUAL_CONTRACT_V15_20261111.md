# A05 | 16の寓意 ビジュアル表示契約 v15 (2026-11-11)

## このブランチの変更範囲
- 16種類の採用モチーフIDと4色のRGBYを、採点エンジンから独立した `visual-contract.mjs` に定義。
- `money` / `time` の2方向に加え、E軸が中間・保留で補助マークを表示しない `null` を許容。
- 表示入力は明示指定のみ。既存の `T01`〜`T16` からモチーフを推定しない。
- node:test の実行のみ。GitHub Actions、質問、採点、スナップショット、保存機構、レポート、本番UIは変更しない。

## 重要な未決事項
従来の `types.mjs` はA〜Dの方向の組合せによる16種類。新しく採用した寓意はA・Bの方向＋強弱を組み合わせた16枠であり、**同じ16個でも番号順の対応は成立しない**。

このため `T01=北極星` 等の暗黙対応は禁止。C×DをRGBYに割り当てる具体ルール、A/B軸の強弱境界、E軸の中間・保留、これらの判定契約を決めるまでは、実診断結果への自動連動を実装しない。

## UI方針
- 既存16モチーフを維持。128は表示の組合せであって診断タイプ数ではない。
- RGBYはカードと画像の枠線のCSS色として表示する。原画への発光合成は現行必須要件から外した。
- 揺らぎは任意の装飾、初期OFF。動きを減らすOS設定に従う。旧発光・濃淡は再利用部品として保管。
- Tier1紋章は16/16初稿、Tier2原画は正式美術承認0/16。仮素材を正式版と誤認させない。
