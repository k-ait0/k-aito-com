- 右：一週間の時間の組み方を新しい形に作り直す

**A-N04｜重複として追加しない**（比較：A03）

**A-N05｜重複として追加しない**（比較：A01）

- 右：暮らしの基本的な型を新しく作り直せなかったこと

## 5. 有望な質問を採点枠へ進めるための検査

1. 6問について、**意味の同じ質問が別名で存在しないか**D-146の50原案に戻ってもう一度確認する。A-N03はA06の用具構成と、D-N02はD-BK13の問いと比べる。
2. 6問の左右を同じ条件で読み比べ、回答に関わる要因を「好む価値」「スキル」「費用」「倫理・義務」「対人関係」「想像可能性」に分類する。特にB-N03は個人の自律志向でなく人付き合いの快適さを尋ねていないか確認する。
3. 条件の違いを問いの独立性とみなさない。たとえばA-N05の住居とC-N04の自由時間は、既存内容の**別提示**でしかない。
4. **完全な意味重複を許可しない**。独立した意味の差がある場合でも同系統の正式採点問は最大2問というユーザー確定規則を維持する。
5. 本人の解釈、回答理由、設問相互の整合性が確認できるまで**採点に組み込まない**。特に希少性、費用差、予想後悔、人物化などは方法効果として留保する。
