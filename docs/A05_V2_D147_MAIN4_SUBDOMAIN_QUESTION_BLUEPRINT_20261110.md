## 比較・受入の基準

各系統に2〜3案を構想し、**次の内容審査**を通過したものだけ認知面接候補へ昇格させる。

1. **軸純度**：左右の違いが主軸の定義に対応し、社交性（B）、不安・計画性（C）、忍耐力（D）、転居可能性や道具好き（A）が主にならない。
2. **条件均衡**：左右で費用・所要時間・成果・権利・実行可能性・希少性を片方だけ変えない。
3. **増分情報**：同じ系統の別問でも、回答が変わる**合理的な理由と条件**が明示できる。単なる言い換えではない。
4. **回答可能性**：就労、同居、資産、特定技能、特殊な活動経験を不可欠な前提にしない。
5. **独立性の監査**：元D-146で重複している疑いのあるIDを明示し、候補数に自動加算しない。
6. **順序・極性**：左右が同時に魅力的になることを認め、七段階の中央と「判断不能」「該当なし」を混同しない。
7. **実証留保**：原文審査と仮想回答の成功は、実回答者による因子構造・信頼性・妥当性の確証ではない。
