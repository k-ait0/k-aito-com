## 3. 状態機械の改訂案（研究版のみに実装する前にレビュー）

- `NO_INFORMATION`：A〜Dの方向回答がすべて0、かつ有効回答も0。成果物は「判定不能」「30問スキップ」、結果ゲージは非数値。中立や拮抗の根拠とはしない。
- `MIDPOINT_ONLY`：A〜Dで有効回答はあるが方向回答はすべて0（典型は全4）。「中間回答が多いが理由は区別できない」とする。全skipの`NO_INFORMATION`とは分ける。
- `LOW_EVIDENCE`：一部方向回答があるが1つ以上の軸で方向判定に不足。各軸の根拠数を提示し、可能な補助質問と限界を説明。
- `MIXED_OR_BALANCED`：十分な有効・方向回答があるにもかかわらず符号や頑健性が拮抗。ここで初めて「拮抗」に近い表現が許容される。ただし現行の閾値は未較正。
- `PROVISIONAL_DIRECTIONAL`：D227の現在の研究用条件を満たした場合のみ参考方向を表示。分類を確定したと扱わない。

これらは**ユーザー向けの状態説明と分岐の要求案**であり、`D227`や`D243`の内部状態ラベルを直ちに書き換える指示ではない。変更時は研究エンジンとブラウザ両方の新しい仕様を揃え、既存D248一致試験との整合を確かめる。
