# A05 D-126｜旧・設問候補の再発掘と重複の原因分析

## 結論：元30問より多く検討した記憶は正しいが、未採用の独立した63問ではない

- 旧ブランチ `feature/a05-d23-modular-diagnostic-20261025` の `D-35` には **37個の文言ペア**（30設問IDに対する原案・修正案）。
- `D-36` は **26個の文言ペア**（13設問ID×2改稿案）。
- 合計 **63個の文言ペア**だが、元の設問IDは **30個**。63問の独立した未採用バンクという意味ではない。分野別 A12／B13／C13／D11／E14。
- 別系統の `D-90` に **B/Cの独立評価尺度12項目**（B6・C6）が残る。これらはA05 v2の強制二極採点とは構造が違う。
- `D-35` にはE05代替として「追加のお金」「追加の時間」を別々に問う **2項目**が残る。これはE二極スコアの追加入力に無校正で変換できない。
- `D-94` ではD-90のC現在価値項目C-P01/P02/P03が **BLOCK_FOR_CP1_AGGREGATE** と評価されており、回収だけで採用可能になるものではない。

## 重複が増えた開発上の原因

1. D-121の40問を**現在の30問の二極テーマから直接派生**させ、過去の原案（D-35/D-36）と元の採否理由を先に確認しなかった。
2. Y/N化・文脈追加を「別質問」として数えやすく、元の30問と似た判断を何度も問う構成となった。
3. 新しい採点情報（境界を解消する判断条件）と、単に言い方が異なるだけの設問を、作問段階で切り分けなかった。
4. B/C/Eの**二極測定構造そのもの**の問題に、同じ二極質問を増やす方式で対処しようとした。
5. D-125でも各軸5問の**数の達成**が先行したため、古い試験案との比較や独立した情報増分の検証は未完了。
