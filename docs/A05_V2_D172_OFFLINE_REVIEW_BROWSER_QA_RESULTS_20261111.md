- スクリーンショットを自動生成したが、**この工程では人間による見た目の受入承認を行っていない**。
- D-170はファイルのオフライン起動を想定。JSONの書き出し先は利用者のローカル端末であり、プライバシーのため外部アップロードや自動保存をしない。

## 4. 次の採否判断

この研究UIで最初に扱うのは、D-171のTier1 4件（A-G2・B-G1・C-G1・D-G1）。回答者が二つの質問をどう解釈するかを検証し、**相談と自律の両立、単なる条件差、意味重複、別軸への交絡**を記録する。
