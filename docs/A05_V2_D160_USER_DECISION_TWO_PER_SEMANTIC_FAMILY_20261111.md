# A05 D-160｜ユーザー確定：完全重複禁止・同系統最大2問

**2026-11-11／このルールは編集方針として確定、設問の採否は未承認。**

> ユーザー決定：「完全重複ではない同系統質問は2つまでの存在を認めます」

## 確定した品質ルール

1. **完全重複は0問**：語句や例を変えただけで、判断する軸・左右の条件・回答理由が同一なら、片方を削除または統合する。2問存在させない。
2. **同じ意味系統は最大2問**：両方を候補に残すには、どの価値判断が異なるか、同じ人が合理的に回答を変える理由が何かを明示する。金銭・責任・技能・所有権・親密度などの外部条件差だけで回答が変わるものは原則不適格。
3. **2問は上限でありノルマではない**：1問しか質の良い質問がない系統なら1問、0問でも構わない。設問数を合わせるための言い換えは認めない。
4. **適用するのは設問バンクの登録段階**：各回30問の抽出だけで上限を守っても、原バンクに同義質問が多すぎる問題は残るため、バンクのA-D各12候補にも上限を設ける。
5. **広い観察領域と意味系統を別管理**：以前のA/B各3つの「観察領域」はテーマの整理単位であり、2問上限を直接適用する意味系統とは限らない。ただし、根拠なく名前を細分化して別系統とみなさない。

**変更しない設計**：バンクA〜D各12＋E2＝50問、毎回A〜D各7＋E2＝30問、主4軸16タイプ、E2問固定。30問フォーム・抽出・採点・公開処理も未変更。

## 設計上の必要条件

主軸1つにつき **12問 ÷ 2問/意味系統 = 最低6系統**。主軸4つで少なくとも**24の真に意味の異なる質問系統**を確保できなければ、品質を守った50問バンク完成とは認めない。24系統が必要という数学的条件は確定だが、24系統の独立性が立証されたわけではない。

毎回7問の出題時も最大2問/同系統なので、1回に少なくとも4系統から出題する必要がある。ただし**ここから系統別抽出エンジンの変更は許可されない**。

## 2問目を許可する具体的判定手順

| 判定点 | 問1 | 問2 | 採用できる条件 |
|---|---|---|---|
| 測定対象の主軸 | 主軸・極性 | 同じ主軸・極性 | 別の能力や生活条件を主に測らない |
| 判断場面 | 例・条件 | 例・条件 | 例を変えただけでなく、別の価値関連情報が得られる |
| 左右の負担 | 費用・時間・成果・権利等 | 可能な限り同等に統制 | 片側だけ有利な設定でない |
| 回答が違う場合の理由 | 回答者の理由 | 回答者の理由 | 価値判断上の説明が成り立ち、単なる条件差に依存しない |
| 重複審査 | 同一の問いか | 同一の問いか | 完全重複なら2問を認めず統合 |
| 独立性の主張 | 未検証 | 未検証 | 2問存在＝別の心理尺度と誤認しない |

**運用順序**：①質問案作成 → ②意味系統IDの仮設定 → ③完全重複削除 → ④各系統2問上限で絞込 → ⑤認知面接の回答理由照合 → ⑥項目分析 → ⑦採点・出題反映の可否を別途承認。
