## 3. Tier1の採用条件

- **現在の表示条件**：既存カード内の116px紋章＋見えるモチーフ名を維持する。
- **24px単独アイコンは採用禁止**：小サイズで細部が崩れるというv22の所見がある。24pxは文字併記・補助用途のみ。48pxの単独採用も人による識別性確認前は保留。
- RGBYはUI側のCSS枠線のみ。原画そのものの赤緑青黄バリエーションを増やさない。
- E軸は `money` / `time` / `null`。未判定・中間を装飾だけで断定しない。
- 新16寓意は旧T01〜T16の番号順と非互換。判定エンジンが確定するまで結果との自動連動なし。

## 4. Tier2キービジュアル｜先行2作品の制作ブリーフ（**未承認案**）

### 共通仕様

1. 人物の肖像ではなく、神話的モチーフを主役にした象徴美術。ロゴやスコア文字は描かない。
2. Tier1同様に色コードは美術作品自体の属性にしない。**RGBYはHTML/CSSの外枠**として別レイヤーで表現。
3. PCは左側ビジュアル＋右側に診断結果、スマホはビジュアル上部＋テキスト下部を想定。見切れを避けるため中心60%に主体と識別特徴を収める。
4. 背景は情報量を絞り、輪郭・シルエットを保護。無関係な小物やUI的文字の描き込みは避ける。
5. Tier1紋章とTier2原画を差し替え可能にし、`<img>` / `<figure>`の周辺はブラウザUI。キャラ名・タイプ名・スコア・装飾枠を画像へ焼き込まない。
6. 人が見る候補作品には`concept`または`unapproved`を付ける。正式採用はユーザーの審査後。

### 先行A：ペガサス（CA-11／変化×自律）

- 視覚核：躍動する翼と前進する馬体。翼の形状、頭部、4肢のシルエットが分離し、翼のない馬や一般的な鳥と誤認しない。
- 構図：斜め上へ向かう重心、空間に余白。自律＝外部から手綱で誘導されない、変化＝移動が明瞭。人間の騎手は描かない。
- 比較ゲート：翼・脚の崩れ、馬体の解剖破綻、画面外切断、文字と被る構図を不合格とする。

### 先行B：カーバンクル（CC-00／変化×つながり）

- 視覚核：小型の幻想獣＋額の宝石。大きな耳・柔らかい輪郭・穏やかな親和性。一般の猫やウサギにしか見えないデザインは避ける。
- 構図：近景で親密さ、宝石が視線の起点。つながりを人間の手や群衆に依存して表現しない。
- 比較ゲート：額の宝石が隠れる、耳・顔が不自然、幼児向けキャラに過度に傾き既存15点と画風が分裂する場合は不合格。

### 人間レビューの採点表（試案）

各0〜3点、計15点：①寓意の識別性、②共通画風との調和、③小画面での構図維持、④Tier1紋章との連続性、⑤UI文字と競合しない余白。**12点以上かつ各項目1点以上**を量産候補の目安とし、最終承認は別判断。正式基準としては未確定。
