# A05 D-38 — 調査データ取扱い・停止・削除の運用案

**版 A05-D38-SOP-0.1｜作成日：2026-10-26｜実行・保存・募集の承認なし**

G1で審査するための作業手順書。保存先・担当者・アクセス権・法令等の適用判断が未決定のため**運用開始不可**。この文書と承認レジスタは一般公開可能な抽象手順のみを含み、個別回答・逐語録・識別子と対応表は含まない。

## 1. データ最小化の原則

| データ種別 | 原則 | 暫定保持案（未承認） | 公開リポジトリ |
|---|---|---|---|
| 募集連絡先 | 原則不要。やむを得ない場合は回答と分離し最小限 | 面接終了後14日以内に削除する案 | **禁止** |
| 仮名IDとの対応表 | 撤回に必要な場合だけ限定管理。集計後に削除 | 面接終了後30日以内に削除する案 | **禁止** |
| 回答値・設問ID・提示順 | 読解調査に必要な項目のみに限定、本人の同意を前提 | 編集判断終了後90日以内に削除する案 | **禁止** |
| 回答の言語化・要約メモ | 事例の特定情報は落とし、引用可能性を別に審査 | 編集判断終了後90日以内に削除する案 | **禁止** |
| 録音/画面録画 | **原則収集しない**。必要な時は個別の追加同意と別ポリシー | 実施した場合はテキスト化終了後7日以内を提案 | **禁止** |
| 非識別化した集計 | 母数・収集条件・判定理由だけ掲載する候補 | プロジェクト記録として保存する範囲を別途審査 | **個票復元不能な集計のみ個別承認後可** |

上記日数は**提案であって実施済みの規約ではない**。実際の保存期間は法令・調査用途と撤回対応を踏まえて正式承認し、参加者向け説明に記載する。

## 2. システム境界とアクセス管理

- 保存先として選べるのは、**実施主体が所有・管理するアクセス制御付きの私的領域**。製品本番のA05 IndexedDB、GitHubのPR・Issue・Actionsログ、一般向けスプレッドシートや本番サイトは不可。
- 保存先のサービス名、地理的な保管場所、暗号化（保存時・転送時）、閲覧者のロール、端末アクセスとバックアップの扱いをG1台帳に記録する。これらは**未定**。
- 調査番号と募集連絡先は別領域。連絡先と調査回答を同じCSVに結合しない。必要最小限の対応表は限定担当者のみ閲覧可とする。
- 外部AI、メール転送、外部文字起こしツールへの研究回答の送信は**承認範囲と参加者への説明が確定するまで禁止**。
- 仮名IDの利用だけで匿名化を宣言しない。少人数と自由記述の組合せからの再識別リスクを点検する。
- 短期保管・定期削除を実現する**手順の実運用テスト**を募集前に完了させる。テストには架空データだけを使用する。

## 3. 面接の取り扱い（承認後の想定順序）

1. 承認された参加者説明資料の版と使用する質問候補のGitコミットを記録。研究責任者、問い合わせ先、保存と削除の方法を確認。
2. 面接・保存の目的と参加・中止・撤回を説明。同意がなければデータを保存しない。
3. 面接者は台本に沿って設問文の理解と負担感を確認。病歴、所得額、政治・宗教、家庭環境の詳細など必要のない情報を尋ねない。
4. 疲労・心理的負担・想定外の機微情報・本人の中断希望があれば**ただちに中断**。余分な詳細は記録しない。
5. データは承認済みの私的保存先にだけ保管。アクセス権と保持期限をデータ種別で分類。
6. 集計時は質問ごとの「提示数」「有効回答」「保留」「辞退」「未提示」「読解問題」「候補順序」などを区別。本人の経験談を詳しく引用しない。
7. 編集結果の公表前に少人数のセル・珍しい属性・自由記述からの識別可能性を確認する。

## 4. 撤回・削除と監査

- **撤回の入口**：参加者へ承認済みの連絡窓口を提示。連絡先が未設定なら募集不可。
- **即時の停止**：撤回の意思を示された場合は、まず進行中の面接・記録を停止する。
- **削除範囲**：個別回答・メモ・録音・対応表・バックアップの有無を確認。削除可能な対象を洗い出し、手順に従い削除する。
- **匿名化済集計の制約**：個人と結び付けられなくなった集計は削除対象を特定できないことがあるため、その境界と締切を同意前に説明する。
- **監査記録**：個人を再特定しない受付番号、種別、対応完了・保留の状態を限定領域で管理。氏名や個票をPRに記載しない。
- **削除結果**：実施責任者が確認し、参加者へ必要な範囲で結果を伝える。対応期限はG1で事前決定する。

## 5. 情報事故と品質問題への対応

| ケース | 初動 | 次の確認 |
|---|---|---|
| 誤って公開Issue/PRへ個票を掲載 | 当該作業を停止、権限のある者に削除・アクセス遮断を依頼 | Git履歴・キャッシュを含む残存影響、必要な通知・報告 |
| 録音の無許可実施 | 即停止、記録を隔離し対応権限者へ報告 | 削除と参加者への説明、運用再審査 |
| 連絡先と回答の意図しない結合 | 転送・解析を停止、権限と流通先を確認 | 復旧・分離・必要な連絡、再発防止 |
| 調査者による診断結果の断定 | 解釈や結果返却を停止 | 説明文と採点禁止ルールの再教育 |
| E05の金額・時間の不公平な比較が顕在化 | Eの二極分類を保留 | 別の設問形式、補助表示、除外を研究会議で比較 |

外部向け通知・報告や保存期間等は**適用要件の確認後**に正式化する。これをもって法的適合が完了したとは主張しない。

## 6. Go/No-Goの運用原則

- G1台帳 `docs/A05_D38_G1_APPROVAL_REGISTER_20261026.json` の全12項目は現在**PENDING**。

- 研究用候補マニフェストにある `scoringAllowed: false`, `personalDataCollectionApproved: false`, `autosaveAllowed: false` の状態を維持する。

- 設問が改訂されても旧保存結果・16タイプ判定の値を自動的に更新しない。
