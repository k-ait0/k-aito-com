## 画像とデザインの所見

1. ペガサスは原画中の主役が小さく空間が広い。カーバンクルは主役が比較的大きく接写的。**現在の2作を単純に統一構図とは呼べない**。セーフゾーンと拡大率を組み合わせ、人が主役の大きさをレビューする。
2. 世界樹の原画では馬や小型獣と違い、根・幹・樹冠・地平線が識別に重要。動物に合わせた狭い主体領域へ過度に寄せると、木と分からなくなる。**動物・自然物で同じ顔アップ比率を要求しない。**
3. RGBYは各寓意に固有の属性ではなく**表示時に与える可変CSS枠線**。今回画像生成された異種16キャラ一覧のR/G/B/Y固定分類と名称は採用不可。
4. 適用できる共通基準は、原画への文字・数値・UI焼き込み禁止、主要モチーフの見切れ禁止、`object-fit:contain`、明瞭なモチーフ名のDOMテキスト併記、PC・スマホでのセーフゾーン確認、Tier1とTier2の状態区別である。
