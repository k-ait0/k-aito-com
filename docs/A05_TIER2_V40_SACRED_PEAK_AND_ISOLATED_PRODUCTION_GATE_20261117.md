## 大きな制作上の問題と修正方法

従来の生成では対象キャラ以外の16枠ポスターが繰り返し出力された。今回はさらに、次に「港」を作るべき工程で霊峰の類似画像が続いた。**港の原画として流用せず、港のステータスは未制作のまま**保持する。

今後は以下の順序を守る。

1. **生成前**：対象の`id/name/slot`を正本から1件だけ選択し、不可要素を明記。既存16枠一覧や属性色のキャラ固定表を生成指示に入れない。
2. **生成後**：まず構図の主題を確認。違う対象、複数モチーフ一覧、文字・フレーム・RGBY固定分類があれば**reject**。ビジュアルが似ていても別の採用枠へ勝手に割当てない。
3. **技術確認**：元PNGの寸法・SHA256、1件の正本ID、レビュー候補／試作合格／正式本番承認という別々のステータスを記録。
4. **表示検査**：白基調A05 UIにCSSでRGBYを後掛け、E軸は手動補助。自動採点・旧T型との暗黙の紐付けをしない。
5. **バッチ終了**：その回の採用数とreject数を明記。受入していない別キャラを「16種完成」と数えない。
