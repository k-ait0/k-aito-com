## 採点方法

7段階回答 `x` を各主軸A/B/C/Dの方向得点へ変換：

```text
d = (x - 4) / 3
score(x) = sign(d) * abs(d) ** 1.5
axisMean = Σscore(x) / 有効回答数
```

1・7の強い回答が、3・5の弱い回答に比べて相対的に重視される。設問の基本重みは均等、Eは16タイプの分類には含めない。

各軸は以下の研究用ルールで判断：

- 有効回答5未満または異なる意味グループ4未満：`INSUFFICIENT`
- 合計方向が0：`TIE`
- `abs(axisMean) <= (1/3)^1.5`：`WEAK`
- 1問または1意味グループを除いたとき符号が変わる：`FRAGILE`
- 上記以外：研究用の`DIRECTIONAL`

未確定軸がある場合は両側を残して16タイプから候補集合を作る（1／2／4／8／16タイプ）。4軸が未確定でも、追加質問は任意で最大2問×2回＝34問。

`(1/3)^1.5` は暫定的な説明可能な閾値であり、統計的な信頼区間や実回答による較正値ではない。
