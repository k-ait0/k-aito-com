## 6. 全件横断分析から分かったこと

1. **A軸**：居住地、活動拠点、情報整理、週間リズムが旧50問にも集中している。新しい候補は物品・自分の儀式・自己記録だが、愛着やB軸の関係性が混ざり得る。
2. **B軸**：個人の最終決定とグループ合意をほぼ同じ構図で聞いた質問が非常に多い。実行過程や援助の受け方という題材を増やしたが、**自己決定と相談・協力は両立する**ので、二極性を確認するまでは採点しない。
3. **C軸**：単発時間と毎週時間の配分は既存と近接。年間の満足の判断基準と目標達成後に優先する価値は別の情報を得られる可能性がある。資金・後悔・希少性の案は交絡や手法効果が強い。
4. **D軸**：分野の数、趣味の種類、創作媒体には多くの同義パターンがある。**調べる疑問の数**、人へ伝える情報の範囲、作品の並行性を分けて検討するが、スキルや能力の影響も調べる。
5. **32の名前は32の実質系統の証拠ではない**。むしろAの所属活動とB軸、Bの独力と協力、Cの活動評価、Dの作品とメディアのように境界不明の系統がある。
6. 文字3-gram近接値は、**表記が似ている候補を探す探索用補助**。低い近接値でも判断内容が同じ場合があるので、類似度だけで採否を決めない。
