## 1. 解消した意味上の欠陥

元のD-170は`middle`の1選択肢に「中立」と「両方当てはまる」を同居させていた。B軸の「自己決定と関係性が両立するか」を検査する場合に、判断不能を招く。

**改修した選択肢**は、`neutral`「中立・どちらでもない」／`both`「両方とも当てはまる」／`neither`「どちらも当てはまらない」／`unknown`判断不能／`not_applicable`非該当を別々に保持する。

旧`middle`データは「旧記録：中立か両方か区別不能」として扱う。過去の回答を自動的に`neutral`または`both`に変換しない。

初回改修では11ケース中1ケースにしか新しい理由欄が追加されず、ブラウザQAが失敗した。全ケースへの展開へ修正し、**全11ケースの新欄存在を検査する再発防止テストを追加**。今回の最終CIでは成功を確認した。

## 2. 記録可能になった情報

各ケースに、比較先の解釈／試作案の解釈／回答の主な理由／主な回答理由のコード／補足メモを追加。研究担当者が記録した**回答理由のコード**は価値判断、意味重複、金銭・時間、権利・義務、能力、関係、公平性・社会規範、遅延割引、その他、判断不能から選ぶ。これにより、意味上の重複と実際の価値判断の差を区別するための情報を収集できる。

**B-G1は自己決定と相談希望の2項目をそれぞれ1〜7で独立評定**。両方に高い回答を許す。研究で得られた両方の評定を、既存B軸の二極得点へ直接変換しない。

## 3. ローカル集計

[集計プログラム](../scripts/a05-d170-research-aggregate.cjs)は、D-170で手動エクスポートしたJSONを読み取り、ケース別に暫定判定と理由コード・選択肢の件数・旧区別不能選択肢の有無・B軸の両評定が高い件数を集計する。

例（ローカルNode.js環境）：

```bash
node scripts/a05-d170-research-aggregate.cjs session01.json session02.json
```

- 結果へ自由記述原文、氏名、ファイル名、個々の回答内容を出力しない。
- JSONのスキーマ、11件のID、軸、回答値を厳格検証する。
- 同一回答者が複数ファイルを出した場合は本人の重複を検出できない。**集計件数は本人の人数とみなさない**。
- 匿名化済みでも自由記述には個人情報が偶発的に含まれることがあるため、研究用原ファイルをGitHubや外部に共有しない。
- 集計は**記述的な件数のみ**。これで心理測定の妥当性・信頼性・独立因子の存在を主張しない。
