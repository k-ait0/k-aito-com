# A05 D254｜30問以降はY/N形式に限定（2026-11-18）

## 決定した仕様
- **第1段階は7段階回答30問のみ**（A〜D各7問、E補助2問）。31問目以降は7段階・二者択一・別尺度による追加質問を出さない。
- 30問終了後、必要な場合の追加出題は**Y/N形式のみ**。現在のY/N形式は`YES` / `NO` / `判断できない（UNSURE）`で、回答を強制せず、途中停止を認める。
- 従来の結果画面の「7段階の追加2問」「30→32→34問」導線は研究用D246から削除する。
- Y/Nの最大8問・左右を独立して尋ねる点・任意の具体場面質問・回答理由の任意選択は現段階では維持する。
- **できる限り16タイプへ分類することが研究目標**。ただしD243/D246の現在のY/Nは非採点で、今回の「質問形式変更」だけでタイプ候補は減らない。Y/Nを分類判定に接続する規則は別の版で設計・検証し、未較正のまま確定結果を表示しない。
- `判断できない`はY/Nの`NO`とは区別する。YES/YES・NO/NOを軸の符号に機械変換しない。
- D242通常版、D227、D243研究用エンジン、50問バンクは変更しない。D246プレビューのUI出題導線のみ変更し、既存の独立パリティ試験は保つ。

## 受入条件
1. 初回の30問は従来の7段階で表示・回答できる。
2. 30問終了後の結果に**7段階追加質問ボタンが存在しない**。
3. 30問終了後、追加質問を希望する場合はY/N画面にしか進めない。
4. Y/N不要時には追加を強制しない。Y/Nを途中でやめても結果に戻れる。
5. 全30問`4`／全スキップでも、31問目に7段階設問が現れない。
6. 既存128×11の計算一致、PC/スマホE2E、D242不変を再検証する。
7. D227の32/34問研究用計算は**互換性研究として保持してよいがD246の実画面からは到達不可**。旧テストを「実画面の32/34問到達」と説明しない。

## 別工程の未解決事項
- Y/Nだけでタイプを判定できるかの条件、拮抗時の具体場面の追加方針、出題8問上限で4軸を十分に確認できるか、分類率と誤分類リスクのトレードオフ。
- D253で特定した全スキップと全4の結果文言、欠測の意味、Y/Nにおけるスキップ理由の分離。
- 認知面接・定量較正は未実施。G1/G3/G4/G5は未合格のまま。

**D254の受入は「31問目以降の質問形式」に限定する。16タイプ分類到達率の改善を達成したと主張しない。**
