## D-45：回答一覧とモバイル表示

| 論点 | 修正前 | 修正後 |
|---|---|---|
| 回答一覧 | 質問ID・値しかなく、どの価値観の設問か判別しにくい | 左右の質問文と「未回答」「回答不能」「中間」「n/7」を表示。編集用ボタンには質問文を含む日本語のアクセシブル名を付与 |
| 進捗確認 | 全体30問の件数のみ | 5軸それぞれ「n/6」の入力数と、未回答数を明示 |

| 画面幅 | 回答一覧が小画面でも3列、PCでは6列のため文章を掲載できなかった | 380px未満1列、380〜699px2列、700px以上3列。質問文を折り返し表示 |

| 共有の開閉 | 同じ「共有文面を表示」というラベルだけで開閉状態が不明 | 開閉に応じたラベル、`aria-expanded`、`aria-controls`、D-44で導入したフォーカス復帰を維持 |

すべて**既存30問の順序、質問ID、採点版、色グループIDを変更しない**。ボタンからの遷移は既存の `moveIndex()` を使用し、保存同意済みなら従来のリビジョン制御による書込みに従う。

## D-46：保存データの書き出しとプライバシー

既存のJSON書き出しには、生回答の任意保存分や旧版・隔離データが含まれ得る。従来は書き出し**後**にその注意を表示していたため、ファイルの機微性をダウンロード開始前に判断しにくかった。

今回、`exportA05Data()` に入る**前**に、JSONの内容と安全な保管が必要な旨を説明する `window.confirm` を追加した。キャンセルした場合は、書き出し処理を開始しない。ファイルの形式や履歴のエクスポート範囲、バックアップ機能は変更しない。通知文の表示方法だけで機微データが暗号化されるわけではない。

既存 `scripts/qa_a05_browser.cjs` のPlaywright/Chrome受入検証を拡張。

1. D-45: 1問回答後の一覧で29問未回答、各カードに左右の質問文と編集ラベルがあり、「最初の未回答へ」で2問目に進み、A01の回答を保持して戻れる。
2. D-44補強: 共有文面に`aria-expanded`と`aria-controls`を付け、開閉をスクリーンリーダーへ伝える。

4. レスポンシブ: 320/390/768/1440pxでタイプ図鑑・回答一覧・質問画面に横スクロールのはみ出しがなく、回答一覧が1/2/3列に切り替わる。
