## 制作規約と画像生成ドリフト対応

1. 採用正本は `A05_16寓意_採用16種_v13.xlsx`（2026-11-10）。`docs/A05_VISUAL_CANONICAL_MOTIFS_V30.json` と突合。画像を生成するために**既定モチーフを差し替えない**。
2. 原画は一枚に一モチーフ。**図鑑、16枠表、キャラ一覧、人格ラベル、タイプ名、進捗表、RGBYバッジ、画像内テキストを含む出力は不採用**。
3. 元のD系神話コンセプトアート、広い奥行き、自然光、節度ある金色のハイライトと白基調A05結果画面を参照する。画像側にUIフレームを描き込まない。
4. RGBYは変化できるCSS枠線で、キャラ固有色ではない。E軸は別UI。旧T01〜T16や診断スコアから新16モチーフへの自動割当は未確定。
5. 人間による試作品合格／本番用最終受入／ブラウザQA／原画の権利審査を**必ず別ステータス**として保持。
6. **再度ポスターが生成される場合は無限再試行しない**。その出力を棄却し、対象モチーフの構図・判定条件を台帳に戻してから別の制作手順を検討する。
