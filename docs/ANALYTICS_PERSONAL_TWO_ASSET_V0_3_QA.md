# K. Aito Analytics｜本人専用ポートフォリオ v0.3（2026-11-12）

**研究ブランチのみ。単一HTML・オフライン・本人専用。商用配信・公式TRの権利承認を意味しない。**

## 今回の実装

- ローカル分析の第3タブ「2資産ポートフォリオ」を新設。
- 2資産＝JPY円現金（利息0％）＋一つの参考資産。参考資産は USD/JPY（米ドル利息0％）、World Bank金公表値（未検証・**投資可能TRではない**）、本人が適法に入手したと自己申告する配当込み総収益指数（INDEX_TOTAL_RETURN、JPYまたはUSD）から選択。
- 初期円現金比率 0〜100％。残余をもう一資産へ配分。月初／月末の引出し、CPI連動／名目固定の引出額、10／20／30年ローリング開始月を維持。
- 3種類の売却順序：円現金優先（不足分のみ投資資産売却）、投資資産優先（不足分のみ現金）、時価比率に従う比例売却。
- リバランス：なし・月次・年次（12か月ごと）。**市場変動と当月引出しの後**に、円現金比率を初期設定に戻す。期間の最終月は不要な売買を行わない。リバランス金額は片道売買額として記録。
- 簡易モードでは「現金優先＋リバランスなし」で固定。詳細モードでは売却順・リバランス変更、開始月別結果と月次保有額抜粋が表示される。
- CSV出力は、各月の期末円現金、期末投資資産、予定引出額、実払額、未払額、運用損益、リバランス片道売買額、条件と品質区分を記録。**実データはブラウザ内のみに保持。**
- HTMLのCSP（default-src/connect-src/object-src none）と外部通信なしを継続。

## 二資産月次計算

月初の資金状態 `cash_0 = initial * cash_percent/100`、`risky_0 = initial-cash_0`。

毎月の参考価値倍率 `q_t = reference_t / reference_(t-1)` は月次に連続する正の公表水準からのみ生成する。

- 月初引出：月0の引出し後に第1月の参考資産値変動を適用。第N回目は月N−1開始、月N末で終了。
- 月末引出：第1月末に参考資産値変動→引出し、第N月末で最後の引出し。
- 各引出月の予定額は `monthly * (CPI_t/CPI_start)` または毎月固定値。
- 払込可能額は円現金＋参考資産価値の合計まで。負残高・借入・追加出資は不可。**残高0であっても当月の支払額を全額払えれば、その月に資金不足は発生していない**。
- 各月後の残高について `closing_total = initial + sum(investment_gain) - sum(actual_withdrawal)`、および `sum(due) = sum(actual_withdrawal) + sum(shortfall)` を許容誤差内で要求する。
- 円現金は金利0％。JPYでのTRの指数比はそのまま用い、USDでのTR指数比は対象月のUSD/JPYで円換算する。USD建てTRにさらに米ドル預金金利を上乗せしない。

**金融モデルの限界：** 税金、口座・NISA、配当課税、取引スプレッド、売買手数料、金保管料、最低売買単位、債券個別償還・再投資、年金・就業収入、複数資産の上位リバランス基準、為替ヘッジ費用は未実装。参考用の現物・為替系列は投資可能なTRではない。

## 本人用TRファイルの受渡契約

正規化月次CSVの必須列：

```csv
month,series_id,value,unit,currency,series_kind,origin,source_id,raw_response_sha256
```

- `month` は YYYY-MM、ユニークな連続月。途中欠損、ダミー埋め、重複を拒否。
- `value` 正の有限数。`currency` は JPY / USD。`series_kind` は INDEX_TOTAL_RETURN **のみ**。`origin` は OBSERVED のみ。指数価格のみ、利回り、CPI、為替、金のスポットをTRと偽装しない。
- `source_id` は登録済み指数提供元（JPX / SPDJI / MSCI / NOMURA_BPI / BLOOMBERG_INDEX / FTSE_RUSSELL）に限定。ファイル内の系列ID・出典・通貨・単位が途中で変わる場合は拒否。
- 自動ダウンロードなし。利用者自身が「適法に本人利用できること」を確認して明示チェックした場合のみ取り込む。
- **データの真贋・ライセンスをアプリが検証・認定するものではない。** CSV内の source_id・raw_response_sha256 は自己申告であり、署名検証済みとは解釈できない。偽造・不正なファイルにも形式面だけの検査をパスする可能性がある。
- ユーザー指定TRの実数値・CSV原本は公開GitHubやHTML本体に同梱しない。
- 金（PUBLISHED_LEVEL_STATUS_UNVERIFIED）は別ファイル・別同意・別の参考価格分類で維持する。
