## 動作仕様

隔離されたHTMLの試作版は、D242の30問・7段階・1.5乗採点を維持し、以下の状態を別管理する。

1. 各軸の初回7問の「4（有効0点）」と「判断できない（スキップ）」を別々に数え、4/null以外の方向回答が全提示項目で4問未満の場合は方向判定を保留。
2. 初回7問で4＋スキップが**5問以上**、かつその軸が未確定の場合のみ、独立Y/Nの任意リンクを結果に提示。
3. Y/Nは左右それぞれの重視度を**独立に**質問し、回答はYES／NO／判断できない。
4. 追加質問はまず1軸2問。理由は任意選択で、文意が分からない／状況で異なる／Y/Nで判断できないなどの場合のみ具体場面をさらに最大2問提案。
5. 研究用Y/Nは**全軸で最大8問**、スキップ・途中終了・後から再開が可能。Y/N回答・理由はいずれも16タイプの加点や候補絞り込みに反映しない。
6. 7段階の追加質問（30→32→34）は従来方式のまま。Y/Nとは**別プロトコル**として扱い、両者の効果を足し算して「診断精度」と主張しない。
7. 面接協力者の回答は保存・送信せず、再読込時に消失する。Y/Nは原本の50問に加えない。
