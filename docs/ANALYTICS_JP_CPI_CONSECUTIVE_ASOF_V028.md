## 小数第1位の指数と「正式な前月比」を混同しない

実際の公表指数 **102.0 → 102.2** の単純比は約 **+0.196078%**。しかし、総務省が公表する前月比は、丸め前の値に基づくことがあり、表示指数からの計算とは一致しない場合がある。統計局も明示している: https://www.stat.go.jp/data/cpi/1.htm

埼玉県の2026年8月CPI概要では、全国総合「102.2」「前月比+0.1%」と表記: https://www.pref.saitama.lg.jp/a0206/a148/202608/2608g.html 。したがって **102.0と102.2から計算した+0.196078%は、8月の正式な前月比+0.1%ではない**。今回の `--compare` は「小数第1位表示値の比率（近似）」としてのみ表示。シミュレーターの正式な物価連動計算は、実際の原本・公表版・必要精度の検証が完了するまで保留。

## as-of デモの動作

同一基準であり、前月より後の公表値を参照しない。各日付に使える最新の公表値だけを選ぶ。

| 決済日 | 参照できる対象月 | 指数 |
|---|---|---:|
| 2026-08-21 | なし（当日公表は時刻仮定せず除外） | — |
| 2026-08-22 | 2026-07 | 102.0 |
| 2026-09-18 | 2026-07 | 102.0 |
| 2026-09-19 | 2026-08 | 102.2 |
| 2026-10-23 | 2026-08 | 102.2 |
| 2026-10-24 | 2026-09 | 102.2 |

実際の数字を使う小規模な**端数込みデモ**：月額基本生活費10万円、決済日2026-09-01／2026-10-01／2026-11-01の参照指数を102.0／102.2／102.2とすると、各月の仮計算額は100,000／100,196／100,196円。これは**過去の公表値で計算方式を確認した結果**であり、正式な公表前月比やユーザー実際の取り崩し額ではない。

## 安全・品質ゲート

1. **固定公表記録**のみ許可。月・数値・公表日・08:30 JST・統計表ID・URLの変更を拒否。
2. 不正な改竄された出所・外部からの市場データ混入を拒否。
3. PDF原本を保有したというフラグ、原本SHAを捏造して主張するフラグ、全公表版取得済み・正式バックテスト可能というフラグを拒否。
4. 公表当日の数値参照、最初のデータより前の数値参照、最終確認日2026-11-13より後への無期限キャリーを拒否。
5. 研究用表示値比率を、公式発表の前月比や時点別の精緻な指数改訂履歴と混同しない。
6. v0.27までの既存テストに加えて、新規42件の独立確認を実行。
