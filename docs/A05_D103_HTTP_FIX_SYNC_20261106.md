### 4つの具体的な修正

1. CSPヘッダーを単なる部分一致ではなく**ディレクティブ単位で解析**。重複・不正な名前を拒否し、`default-src`・`script-src`・`style-src`・`connect-src`・`object-src`・`base-uri`・`form-action`・`frame-ancestors` の期待値を明示検査。
2. 同一CSPディレクティブの重複と不正な構文を不合格にする。
3. `Content-Type`のMIMEを`text/html`と厳密照合し、`text/html-evil`等の前方一致を拒否。
4. 明示承認済みステージングURLはHTTPSで、承認ホストが厳密一致し、ポートが既定443以外なら拒否。

検査用のCSPパーサーは**A05用途の限定的な契約チェッカー**であり、ブラウザCSP全構文の検証器ではない。
