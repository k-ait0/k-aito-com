## 128セット×各条件128人分の人工回答実験

*この実験には実際の人の回答は含まれない。既知の回答方向を仮定し、設問ごとに人工的な揺らぎを与えて判定コードの挙動を比較しただけであり、信頼性係数・精度・心理特性の検証とは異なる。*

| 人工回答の条件 | 現行式：複数タイプが出た人 | 現行式：境界にかかった回答セット | 現行式：残る候補タイプ平均 | C保留3問を除いた対照式：複数タイプが出た人 |
|---|---:|---:|---:|---:|
| 強い方向性 | 0% | 0% | 1.00 | 0% |
| 中程度の方向性 | 0% | 50.27% | 1.85 | 0% |
| 中間に近い方向性 | **85.94%** | **100%** | **13.16** | **83.59%** |
| 意味グループによって反応が違う | 15.63% | 78.60% | 3.42 | 16.41% |

解釈：
1. 明確な人工パターンでは安定するが、中間に近い人工パターンでは出題セット差が単一タイプを大きく揺らす。
2. D222の暫定33.3%境界は保留・複数候補を多く出し、**曖昧な状態を無理に確定しない代わりに、情報量が少なくなる**。
3. C31・C32・C36の採点保留を除くと**編集上の不整合は減るが、人工データ上の結果安定性が一貫して向上するとは言えない**。編集・内容上の適格性とタイプ安定性は別指標である。
4. 128フォームはコードの規則に従う限定サンプル。実参加者に対する誤判定率や再受検一致率を推定したものではない。
