## 3. 全タイプ共通の誤認防止文

> この結果は今回の回答傾向を整理した仮の分類です。性格・能力・適職・将来の行動を確定する診断や、標準化された心理尺度ではありません。回答時の状況や不足回答によって結果が変化・保留される可能性があります。

この警告は表示検討用であり、既存UIへ自動追加しない。利用者が結果を「固有の人格」「能力」「相性」「向いている職業」「将来の行動」などと誤解しないようにする。必要であれば名称・アイコン・キャラクター描写を測定文言から視覚的に分離する。

## 4. レビュー条件

1. **軸と符号の照合**：T01〜T16が現行エンジンのA/B/C/D正負順序に一致するかを自動検証する。安定／変化、自律／関係、将来／現在、探索／深耕を逆転しない。
2. **案Lと案Mの混用禁止**：同じタイプIDに2文面が存在しても、本番での同時混在や保存済みの旧版結果への上書きはしない。概念を採用する段階で`QUESTION_SET_VERSION`、`TYPE_VERSION`、`CONTENT_VERSION`、必要に応じ`SCORING_VERSION`を適切に新規管理する。
3. **推論できない断定の除去**：現実の生活実績、転居・人間関係の有無、対人能力、職業適性、特定の将来行動を結果から確定しない。
4. **暫定・保留表示**：最低回答数や境界の判定は旧エンジンのままとし、実装前に新版での検証を別途行う。4軸で判定できなければ無理にT01〜T16へ割り振らない。
5. **説明の理解性**：人を対象とする検証にはG1運用許可・同意・データ保護・撤回手順を要する。実回答者や参加者を収集したと主張しない。
