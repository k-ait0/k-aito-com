# K. Aito Analytics — v0.26 CPI公表基準年切替え・連鎖方式

2026-11-13 / 個人・研究専用 / 本番反映なし

## 変更点・解消した不備

v0.25のCPI as-ofモデルは2025年基準・接続指数だけを対象とし、歴史上2026-08-07以前には存在しなかった2025年基準を1980年等の時点にも使えてしまう条件をモデル上で排除していなかった。v0.26では独立した基準年検証Coreと、旧・新指数を直接割らない *monthly chain-link* 計算を追加した。v0.25の既存モデル・入力仕様は変更していない。

### 実際の公表開始日（総務省一次資料）

| 系列 | 基準年 | 遡及値の初回公表 | 初回遡及で対象となる最新月 | 根拠 |
|---|---:|---|---|---|
| `JP_CPI_HEADLINE_2015_BASE` | 2015 | 2016-08-12 17:00 JST | 2016-06 | https://www.stat.go.jp/data/cpi/2015/pdf/2015_sche.pdf |
| `JP_CPI_HEADLINE_2020_BASE` | 2020 | 2021-08-06 15:00 JST（公表スケジュール） | 2021-06 | https://www.stat.go.jp/data/cpi/2020/pdf/2020_sche.pdf |
| `JP_CPI_HEADLINE_2025_LINKED` | 2025 | 2026-08-07 | 2026-06 | https://www.stat.go.jp/data/cpi/2025/sokyu.html |

これは**各基準年の初回公表日**だけの独立確認であり、後続の月次CPI報告書の実際の各公表日・数値は取得/認証していない。日付とSHAをJSONに記入しても証拠にはならない。新Coreはこの3種類以外の基準年を**拒否**するため、1980年などの当時の真のas-of情報は未対応。2010年以前の系列は今後別個に公式資料と履歴を確認してから許可する。

2025年基準の遡及接続指数は古い1980年の月に対する数値を持ち得るが、その数値が1980年時点に公表されていたことにはならない。総務省は接続指数で変化率を再計算せず各基準の公表値を用いると説明している。従って新旧基準を単に割る行為は禁止。

## v0.26アルゴリズム

- 同一暦日の公表は時刻不明として利用せず、決済日**より前**に公表された最新のスナップショットのみ選択。月初決済は月初の1日、月末決済はその月の末日。予備モデルのMONTH_ENDは運用収益適用後の決済。
- スナップショットは日本CPI全国総合、`NSA`、`OBSERVED/ESTAT` または `SYNTHETIC/SYNTHETIC_FIXTURE` のどちらかに固定。取得元識別子と基準単位の組合せを検査。基準年が後退するスナップショットの並びを拒否する。
- `OBSERVED_RESEARCH` は、その基準の初回遡及公表日より前のスナップショットを拒否。初回公表日の版には、その際まだ公表されていない翌月以降の観測を含めない。月次指数の先取り・不正な月・未知フィールドを拒否。
- 各ローリング開始月の最初の参照CPI月を固定し、**最初の月の生活費はベース額**とする。以降、直近の参照月が前月と変わらなければ物価調整0。参照月が進んだら、その時点で選択された**単一の新しい公表版の中で** `CPI(新参照月) / CPI(前回参照月)` を求め、前回までの累積倍率に掛ける。
- 旧版6月CPIが106、新版6月が110でも、**観測月が6月のままなら倍率は1**。新版8月133.1・新版6月110なら倍率は1.21。旧106と新110を直接割ることによる疑似物価上昇を発生させない。
- 新版に前回参照月が含まれない場合は `excluded_no_overlap`。新版の参照月が過去に戻った場合は `excluded_regressing_reference`。一度も利用可能なスナップショットがない場合は `excluded_no_published_release`。市場欠損は別に数える。実測値を推測補完・外挿しない。
- 収入・年金・一時支出は生活費CPI倍率の対象外。資産管理・年金期間・月初／月末処理はv0.24/v0.23のCoreを呼び出し、計算結果の台帳を元入力と独立照合する。
- **精度の制約:** 各公表版の指数は通常丸められた水準値のため、実際に公表した前月比・前年比等とは一致しない場合がある。再基準化を踏まえたこの連鎖方式は私的シミュレーション上のひとつの定義であり、官公庁が保証する正式な物価調整方式ではない。

## 厳密な制限・次のゲート

1. 現段階で実際の月次版アーカイブの全歴史とSHA照合は未完了。各版の`source_snapshot_sha256`はユーザー入力の**未認証の申告**。`actual_individual_release_dates_verified=false`、`source_snapshot_bytes_authenticated_here=false`、`historical_funded_fraction=null`を固定。
2. 旧Shiller・Fed・日本CPIの暗号化正本は別の実データ受入工程。秘密鍵なしで復号していない。JPY名目/実質の正式な10年・20年バックテストの完成ではない。
3. 過去の歴史的な基準年について、各年当時の国のCPI月報・公表日・元データを真正なアーカイブから収集・照合して初めてas-of実測と呼べる。元データ使用許諾の公開判断も別審査。
4. `main`、本番サイト、DWZ PR #70 は一切変更しない。
