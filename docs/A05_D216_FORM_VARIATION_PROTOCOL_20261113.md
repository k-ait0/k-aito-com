# A05 D-216｜全50問回答からの30問抽出差・検証プロトコル

## 今回実装したもの

- 入力：D210研究用フォームの**全50問回答JSON**（回答者本人が明示的に書き出したもの）。
- プログラム：`scripts/a05-d216-form-variation.mjs`
- 回帰試験：`scripts/test-a05-d216-form-variation.mjs`
- 同一の全50問回答に対し、固定シードによる研究用30問抽出を既定256回実施し、A〜D各7問について選択肢1〜7の中間値4との差（右方向・左方向・同点）の出現数を集計する。
- **個人別結果・生回答・自由記述・セッションIDは出力しない**。入力JSONは外部送信しない。
- E軸は独立2問なので方向別統計に合算しない。補助的な回答として別に扱う。
- 16タイプ、性格判定、信頼性係数、正式得点は計算しない。

## 何が分かるか

- **同じ50問の回答ベクトル**を前提に、抽出した7問の構成だけを変えると、軸の相対的な回答方向が左右どちらにも変わる場合があるか。
- 一人の全12問が右寄りでも、ある7問だけを抽出すると左寄りになるようなケースを検出できる。
- 全回答が左右どちらかに一様な場合、模擬抽出では方向が変化しないことを確認できる。
- 無回答・判断不能がある軸は無理に補完せず、その人の当該軸のフォーム比較を保留する。

## 何が分からないか

- 全50問を回答したときの順序・疲労効果と、実際に30問だけ回答したときの反応差は、この方法では分からない。
- 同一人の回答内容が時間とともに変わること、事例によって違う選好を示すことは、抽出差とは別の現象。
- 二極尺度の中点は「両方高い」と「両方低い」を区別できない。D210のB/C独立評定はこの問題を調べるための**非採点**の追加項目。
- 軸内の項目が同じ構成概念を測っているか、16タイプ分類が妥当か、実データの信頼性が十分かは、抽出シミュレーション単独では判断できない。
- 合成データで検査した方向逆転率は、現実の回答者の不安定さを示すものではない。

## 実行手順

開発ブランチをチェックアウトしたNode 22環境で：

```bash
# 異常系や合成プロフィールに対する回帰テスト
node --test scripts/test-a05-d216-form-variation.mjs

# 入力なし。未収集であることをそのまま報告
node scripts/a05-d216-form-variation.mjs

# 実回答JSONが収集できた場合だけ、手元の端末で実行
node scripts/a05-d216-form-variation.mjs ./review-01.json ./review-02.json
```

ファイルは手元の非公開領域に保存し、GitHubや公開サイトへアップロードしないこと。集計結果も人数が少ないと個別回答の推測に繋がるため、公開用の生データと混同しない。
