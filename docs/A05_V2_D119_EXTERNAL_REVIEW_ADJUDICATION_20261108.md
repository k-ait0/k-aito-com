# A05 D-119｜外部クリティカルレビューの採否とv2実原本24問照合

2026-11-08／**第三者AIレビューの事実確認・編集監査**。元レビュー本文は別チャット受領。引用表現を公式の実証済み判断とみなさない。PR #76はDraft、公開変更は行わない。

## 1. 本当に採用する論点

1. **構成概念の定義が先**：B/C/Eで「絶対的重視度」か「制約下の相対的な意思決定基準」かを明示し、その測定目標に沿って質問を作る。
2. **A/Dの概念混入対策**：Aは生活・活動の基盤やルール、Dは知識・活動テーマの幅と深さとする仮説を比較。A02/D03、A05/D04、A03/B02など実設問を再監査する。
3. **微差の単一タイプ名を止める設計検討**：合計+1/-1の軸を単一タイプ名に直結させないUI案を、表示コントラクトを変えずに研究。
4. **16タイプを自然に存在する人間の16類型だと主張しない**：編集的な座標索引の可能性としてのみ扱い、検証が済むまで分類を無条件に公開しない。
5. **認知面接・予備調査は必要**：5〜8名は理解度の探索であり、20〜30名の予備データで安定性やタイプ成立を立証したとは言えない。

## 2. 修正・不採用とする外部レビューの断定

| 指摘 | 裁定 | 確認根拠と修正 |
|---|---|---|
| 判断不能と中立が同じ0点として処理される | **v2の現行不具合としては誤り** | `scoreAssessment`は`null`を`continue`して有効回答`n`を増やさない。回答4は`n`を増やし合計0加算。 `n<4`で`direction=null`、分母`3*n`で正規化している。 |
| 6問の合計以外に平均得点へ改修が必要 | **対応済み** | `value=100*weightedSum/(3*validCount)`。欠測時の有効回答数比例の閾値や、保存後の表示は別途検証対象。 |
| 分散を取れば「両高で葛藤」対「両低で無関心」を完全識別できる | **不採用・識別不能** | 全問4の回答列は「両価値高いが相殺」も「双方とも無関心」も含み得る。同じ観測データから重要度を復元できない。例`[7,7,7,1,1,1]`と`[4,4,4,4,4,4]`の分散差は質問間のばらつきを示すが、両方の重視度を示さない。「葛藤型/無関心型」の性格ラベルは禁止。 |
| 3問の独立尺度はαが崩壊し不可能 | **誇張** | 3項目尺度は原理的に不成立ではない。ただし内容範囲・測定精度・α/ω・再検査を評価し、項目数の設計妥当性を実証する必要がある。 |
| B2/C2なら全員高得点となり識別力ゼロ | **実証なし** | 天井効果・社会的望ましさは**検証すべきリスク**であり必然の結果ではない。B1/C1は相対選好の別構成概念で、二極にすれば妥当性が保証されるわけではない。 |
| 強制選択にすれば二極尺度が科学的に成立する | **条件不足** | 二極的な「相対配分」という新しい設計目的は作れるが、項目の便益量・コスト・社会的望ましさを一致させなければ、測定対象が定まらない。強制選択/ipsative分析には固有の制約がある。 |
| 相関|r|>0.6なら16タイプの一部セルが不存在 | **誤り** | 相関が高いと組合せに偏りが生じ得るが、観測セルが必ず0になるわけではない。相関係数は事前に固定された失格基準としない。 |
| 境界±2なら60〜70%に単一タイプを出せる | **実測根拠なし** | 6問の7段階を独立一様と仮定した数学分布で、4軸全て`|sum|>2`の割合は**14.58%**。従来`sum!=0`は**71.85%**。この仮定は実回答者の確率モデルではない。 |
| A05/E05の対案はすぐ採用可能 | **未承認** | A05で人間関係の再構築を含めるとBとの混同が残る。E05の「大きく増える」は定量アンカーを未設定で条件の同等性は保証されない。 |
| 中央なら必ず隣接2タイプ表示 | **UI比較案として保留** | 1軸のみ境界なら候補は2つ、2軸なら4つの可能性。既存タイプ説明の正当性、誤解、視覚的な確定印象を別途評価する。 |

## 4. 数理的な境界ゾーン（合成一様分布のみ）

1軸7^6＝117649通り、各項目の1〜7が独立一様と仮定した場合：

| 四軸のタイプ名発行条件 | 4軸同時に通過する仮想確率 |
|---|---:|
| 各軸`|sum|>=1`（現行v2） | 71.85% |
| 各軸`|sum|>=2` | 34.26% |
| 各軸`|sum|>=3`（レビューの中央±2保留） | 14.58% |
| 各軸`|sum|>=4` | 5.49% |

**実利用者の割合ではない。** さらに標準誤差（SEM）、再検査一致率、境界の最適値は実測なしに判断できない。`sum=+1`→1回答1段階変更で0（方向保留）にはなるが、別極性-1への直接ジャンプは起きない。単一回答2段階以上の変化なら直接反転はあり得る。

### 外部根拠の位置づけ
- [COSMIN content validity: relevance, comprehensiveness, comprehensibility](https://pubmed.ncbi.nlm.nih.gov/40562250/)：構成概念と設問理解の検証手順の参考。A05尺度を直接検証する資料ではない。
- [Forced-choice/ipsativeの限界](https://pubmed.ncbi.nlm.nih.gov/23148475/)：相対比較の統計上の注意。A05の同一人物内比較方式がその論文のMFC構造と同一と断定しない。
- [Three-item scale consideration](https://onlinelibrary.wiley.com/doi/10.1002/hrm.21852)：3問尺度を一律排除しない。妥当性の保証ではない。

**結論：レビューの設計方向には重要な示唆があるが、全採用は禁止。B/Cの対象概念、A/Dの区別、弱い方向のタイプ表示を先に定義・比較し、それ以外は候補のまま保持する。**
