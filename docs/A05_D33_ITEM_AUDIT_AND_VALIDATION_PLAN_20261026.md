# A05 D-33 — 30問の編集監査・E軸再設計・検証計画

2026-10-26策定。D-31改訂候補を対象とする**設計上の仮評価**であり、回答者調査、心理計量的な尺度検証、専門家による査読の実施結果ではない。現行質問セット `A05-Q-1.0.0-draft` とSHA-256、採点・16タイプ定義・IndexedDBは無変更とする。

## 1. 測定概念と判定基準

| 軸 | 仮の操作的定義 | 混入させないもの |
|---|---|---|
| A 安定／変化 | 活動・生活の進め方を継続する／更新する優先度 | 転居可能性、経済力、Dの経験の広さ |
| B 自律／つながり | 同じ活動の意思決定・進行で自己裁量／他者との協働をどれだけ重視するか | 外向性、対人能力、他者への思いやりの優劣 |
| C 将来／現在 | 活動の効用を将来／今日のどちらの時点で得ることを重視するか | 自己統制の善悪、長期幸福、外発／内発動機 |
| D 探索／深耕 | 経験する対象の幅を広げる／特定対象を深く掘り下げる優先度 | 転居意欲、人脈、単なる変化耐性 |
| E 経済／時間 | 必要な生活費・休息が確保されたという条件で、追加的な支出裁量／時間裁量のどちらを先に増やしたいか | 所得水準、労働時間、育児介護、生活の優劣、時間の金銭換算 |

これは**心理尺度の妥当性を確立した定義ではない**。A/D、B/外向性、C/現在満足度、E/生活窮迫などの概念交差をインタビューで点検する。

判定は **BLOCK**（改稿しない限りv2採用停止）、**REVISE**（対称性・文脈重複の改善）、**TRIAL**（認知インタビューに投入できる候補）とする。TRIALも採用済みや検証済みを意味しない。

### E軸の共通指示案

> 生活に必要な収入と休息が確保され、どちらの選択肢も現実的に選べる状況を想像してください。どちらも大切なら、今、先に増やしたい方を選んでください。判断が難しいときは「判断できない」を選べます。

**注意：** 生活基盤の確保を仮定できない人にとって不自然な質問になり得る。認知面接でこの仮定を理解・適用できるかを確認する。実現可能性を揃えることは金額・時間の**交換率の等価性**を意味しない。

## 4. 7段階回答の解釈と選択肢

「4＝同程度」には、(i)双方とも強く重視、(ii)双方とも重視しない、(iii)条件次第で比較不能、が混在し得る。無回答（null）は中立4と明確に異なる。

- **方式1：現行維持**。7段階＋「判断できない」。回答理由は調査で別途確認。
- **方式2：7段階を維持し理由だけ任意の別設問で確認**。「どちらも強い」「どちらも弱い」「状況による」等を区別する。診断本体へ追加するにはプライバシー・保存同意の仕様改訂が必要。
- **方式3：B/Cの両立が広範に確認された場合**、独立した2つの同意尺度へ変更する案を別設計として比較。これは16タイプ・得点との互換を維持できるとは限らない。

中立回答は人格的な曖昧さを意味しない。B/Cの二極性を心理学的事実と断定しない。

## 5. 実施していない検証の実施案

**段階A：認知インタビュー（目安8〜12人）**。数は問題発見の初期目安であり代表性の証拠ではない。就業・非就業、年齢、世帯構成、介護育児、所得・時間制約に多様性を持たせ、回答者の個人情報は最小限にする。全30問の理解／選択理由／迷った箇所を聴く。特にE05α/βの順序を参加者間で変え、想定金額・時間・負担・実現可能性を質問。B/Cは両立するか、A/Dはどう区別したかを確認する。

**段階B：探索的な小規模予備調査（目安60〜120人）**。サンプル数は暫定で、心理尺度の構造や信頼性を統計的に証明するものではない。項目ごとに1〜7の分布、null、4、回答時間、両極への偏り、左右位置の影響、項目同士の冗長さを検査する。回答順序・左右反転・設問版を事前登録し、任意の再検査協力を別途検討する。

| 指標 | 予備的なレビュー着手ライン（合格基準ではない） | 追加確認 |
|---|---|---|
| null選択率 | 10%超 | 読解の困難／適用不能理由／特定状況への偏り |
| 4中立率 | 40%超 | 両方重視／両方弱い／比較不能のどれか |

| E05の想定効果量 | 回答者間で大きな解釈差 | 金銭・時間の比較として成立するか |
| 同軸の重複 | 理由・例示が同じになる項目群 | 文脈を分散、冗長項目を改稿 |
| 所要時間 | 極端な長時間項目 | 難解語・認知負荷・UI要因 |

閾値はチーム内の早期発見の目安であり、心理計量の妥当性を認証するものではない。利用データを集める場合は匿名化だけでなく、回答者への目的説明・任意参加・明示同意を前提とする。
