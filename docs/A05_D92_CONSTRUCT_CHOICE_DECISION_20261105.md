# A05 D-92｜B「つながり」・C「現在充実」構成概念の意思決定基準

記録：2026年11月5日（JST）／対象PR #61（Draft）／状態：**編集上の暫定推奨、正式決裁は未了**。

## 1. 結論（製品承認ではない）

「B 自己裁量 ↔ B つながり」と「C 将来達成 ↔ C 現在充実」を1本の二極軸として無条件に解釈することを避ける。D-90の独立した4尺度で、**Bつながり＝相互的なつながりを重視する価値、C現在充実＝現在の経験自体を重視する価値**を暫定的な編集上の第一候補とする。

- **B第一候補 BR1**：人との相互的な関係に価値を置くこと。「いま人間関係が良いか」「話せる人が存在するか」「援助が受けられるか」とは区別。
- **C第一候補 CP1**：将来の成果に直接つながらなくても、その時点の活動・経験を価値あるものとして重視すること。「いま幸福か」「即時報酬に流されるか」「マインドフルネスが得意か」とは区別。
- **正式な構成概念の承認＝PENDING**。第一候補という編集判断は、統計的優位、尺度妥当性、研究承認、公開承認を意味しない。
- **従来の16タイプ／32派生の製品構想を削除しない**。独立4尺度から旧タイプへ無断変換することも禁止する。

## 2. 設計案の横断比較

| 対象 | 候補 | 現段階の編集判断 | 理由 |
|---|---|---|---|
| Bつながり | BR1：相互的なつながりの価値 | 暫定推奨 | 現状より「大切にするもの」へ焦点を絞りやすい |

| C現在充実 | CP1：現在経験の内在的な価値 | 暫定推奨 | 現在を重視する価値と実際の幸福状態を分けやすい |

「採用候補外」はその概念に研究価値がないことを意味しない。**A05の目的に適合しない**という編集上の判断である。

## 3. 比較基準6項目（数値評価・相性スコアに転用禁止）

1. **価値／状態**：その人が何を大切にしたいかを聞けるか。現況・能力・行動頻度と混同しないか。
2. **弁別性**：B自己裁量、C将来、A環境、D経験、E資源の各概念と区別できるか。
3. **独立高低**：自己裁量とつながり、将来と現在が、双方高い／低い回答でも矛盾しないか。
4. **生活状況の頑健性**：交流機会・自由時間・現在の満足が不足していても、価値を回答できるか。
5. **3問への操作化**：同一概念の異なる側面として3問を作れ、二重質問・言い換え重複を回避できるか。
6. **説明可能性**：結果を「回答上の価値の重視」に限定し、心理的な人格の本質・適職・相性を断定しないか。

## 5. 承認前の架空シナリオと研究上のゲート

合成シナリオを6件定義：
- 自己裁量とつながりが両方高い／両方低い
- 将来と現在が両方高い／両方低い
