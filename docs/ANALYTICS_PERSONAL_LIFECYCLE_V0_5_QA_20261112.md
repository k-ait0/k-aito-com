## 1. 追加済み機能

既存v0.4の円現金＋投資参考資産の2スリーブ、月初積立、月初／月末取り崩し、月次／年次リバランスを維持したうえで、詳細モードに以下を追加した。

- 給与の資産流入額（月額、開始経過月、終了経過月）。金額は利用者が決める**資産へ実際に流入する額**であり、税引前給与を自動で可処分所得へ換算しない。
- 年金の資産流入額（月額、開始経過月、終了経過月）。受給日・実際の税・社会保険料・年金改定などの法制度は再現しない。
- 一回限りの臨時収入／臨時支出（金額、経過月、種別）。ブラウザーUIは1イベント、計算APIは最大20イベントに対応。
- 収支を月次台帳・派生CSVに個別表示。通常出金＋臨時支出の実払い・未払いを保存。
- 詳細モードの設定値は簡易モードの結果に**影響しない**。画面の簡易／詳細を切り替えたら計算条件もそのモードに切り替わる。
- 設定値は0以上の整数円で検証。重複ID、無効期間、負額、小数円、不明なパラメータを拒否。

## 2. ローリング検証の期間定義

開始した市場月を相対月0とする。月初の積立・給与・年金・臨時入金→臨時支出→（通常出金を月初指定ならここで実行）→当月の市場価値変動→（通常出金を月末指定ならここで実行）→期末処理。

実装上の月次台帳は期間境界に「その月の月末出金」と「次の月の月初入金」を同じ年月行で記録できるため、行の意味は**月末時点の変動と翌期間開始処理を合算した境界スナップショット**であり、取引所の当日約定を再現するものではない。期間N月の最後の境界には余分な入金を加えない。

- 給与・年金は開始経過月を含み、終了経過月を含まない区間 [start,end) で加算。終了未指定（無期限）は未対応。
- 臨時イベントはその経過月に1回だけ発生。開始月を別の歴史年に変えても経過月オフセットを維持する。
- 給与・年金・臨時流入は名目固定。標準の毎月の生活支出は従来どおり**名目固定か日本CPI連動**で選べる。
- 履歴期間外のイベントはそのローリング窓では不発生。後からイベントを補完しない。

このシーケンスは既存Personal Labの月初・月末選択を保持したもの。別研究ブランチのAnalytics Lifecycle Core v0.3が採用する「期首積立＋年金＋臨時入金 → 生活費＋臨時支出 → 市場騰落」とは、**月末引出し指定時に計算時点が異なる**。単一資産でのDWZ 192ケース一致検証は従来の**積立・年金なし**の計算限定であり、v0.5全条件がDWZと一致すると断定しない。

## 3. 保存則と不足・後日入金

月末残高 ＝ 初期資金 ＋ 累積定額積立 ＋ 累積給与流入 ＋ 累積年金流入 ＋ 累積臨時収入 ＋ 累積運用損益 − 累積実支出。

累積予定支出（通常＋臨時）＝累積実支出＋累積未払額。

臨時支出の予定・実払い・未払は独立列で監査できる。最初の不足月は後日の入金によって取り消さない。最初の残高0到達月も別に記録する。未払額を後の入金から自動返済するモデルではない（不足は履歴上保持）。

**重要**：給与・年金・毎月積立を同時に入れると二重計上が起き得る。月次積立は給与・年金とは別に資産へ入る資金として扱う。税金・健康保険料・年金の実受給額は計算機が自動推定しない。
