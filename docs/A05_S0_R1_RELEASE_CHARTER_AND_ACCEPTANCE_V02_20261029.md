## 0. 決定済みの3方針（ユーザー明示承認）

- DEC-R1：**R1相互理解ガイドを先行する**。関係の良し悪しの判定、点数・相性ランク・成功確率・良否色は採用しない。R2は別プロジェクト、別研究・別公開ゲート。
- DEC-B2：**B2（自律とつながりの独立2尺度）を研究上優先**し、B軸・16分類が未決の間は**既存診断の自動分類結果をR1へ接続しない**。B1を科学的に確定させたとみなさない。
- DEC-GENERAL：**R1初期版は関係文脈を問わない一般の相互理解表現のみ**。恋愛・家族・友情・職場それぞれの成功・優劣・適合予測は行わない。

以下、各ゲートの合格は「必要な方針がユーザーに明示承認され、固定した証跡があること」を意味する。実装が済んだことは意味しない。

## 2. 推奨ユーザー向けコピー（S0-2案・未承認）

| 場所 | 表示案 |
|---|---|
| タイトル | **16タイプ価値観関係マップ** |
| 導入 | **2つのタイプの、共通する視点と異なる視点を整理します。** |
| 解説の定常ラベル | **A05の暫定タイプ設定に基づく比較です。実際の人間関係の相性や未来を判定しません。** |
| 同型のセル | **同型（設定上4軸一致）**。0点、Sランク、好相性のアイコンにしない |
| それ以外のセル | 軸ID別の『共通』『相違』。構造差を良い/悪い色に変換しない |
| 原典の案内 | **参考研究は一般的な人間関係の研究であり、A05の各組の相性を検証したものではありません。** |

既存画像にあった「同型＝非常に良い／0軸一致＝難しい」は**不採用の撤回済み表現**。キャラクター表情・矢印・RGBYでも暗黙の良否判断を生ませない。

## 3. R1入力/出力契約（S0-3案・未承認）

- **入力**：利用者がキャラクターとして選ぶ2つのT-ID。順序を変えても同一ペア、選択順の左右表示だけ切り替える。
- **保存**：初期リリース候補は選択の保持なし（ページ表示中の一時状態のみ）。Cookie、LocalStorage、sessionStorage、IndexedDB、リモートDBへ保存しない。第三者計測は使わない。
- **出力A（仕様事実）**：暫定4軸の共通点・相違点・同型を含む136組の組ID。0〜4軸差分は構造属性であって良否ではない。
- **出力B（一般研究）**：S2で人手承認された範囲だけ。出典・対象・適用限界の明記がない場合は表示しない。
- **出力C（編集仮説）**：共通の観点・確認したい相違・盲点・対話の問いを、同型16組と異型120組に偏らず記載。直接効果として断言しない。
- **非機能**：ルーティング・画像・社内分析コードなどからもタイプIDをサーバーへ送らない。静的なHTML/MJS/CSS等の配信リクエストは除く。詳細な実装監査はS6に委譲。

**STOP/NO-GO（案）**：いずれか発生時は公開・ロールアウトを止め、原因・再検証・差分を台帳へ記録する。

1. 点数・相性ランク・関係成功の断定がUI/マトリクス/画像に復活。
2. B1の二極性や16タイプを検証済み人格分類として表示、または診断の自動分類をR1に無承認接続。
3. 136組や原本の不一致、上下非対称、同型0点、再現可能な重大表示バグ。
4. 研究の出典がA05個別相性を検証したかのように誤用される、または学術レビュー未完の一般研究を証明扱い。
5. G1等の必要承認のない人を対象とするデータ収集や、決めた入力/保存/送信境界からの逸脱。
6. 未割当の承認者、独立二次レビュー/ローカルQA/iOS実機QA/理解度検証/復旧テストの未了。
