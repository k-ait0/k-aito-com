# A05 D255｜30問＋Y/N暫定分類の研究用実装・検証方針

作成日：2026-11-18 JST。対象：`/preview/yn/` の研究版。正式版D242・D227・D243は不変。

## 設計目的と境界

D254で確定した「1〜30問は7段階、31問目以降はY/N形式のみ」を保持しつつ、未確定のA/B/C/D軸の方向を**研究上の暫定仮説**として補完し、できるだけ16タイプの候補を絞る。

- 従来の30問で確定した方向（D227の研究用基準）は優先し、Y/Nでは上書きしない。
- 初回30問で方向未確定の軸をY/Nで補完する。5/7という旧Y/N誘導条件だけに依存しない。
- 左右独立Y/N2問が `YES/NO`（左のみ肯定）または`NO/YES`（右のみ肯定）なら、暫定方向を付ける。
- `YES/YES`、`NO/NO`、`UNSURE`、片側未回答では方向を決めず、予算が残ればその軸の具体場面Y/N2問へ進む。
- 具体場面の回答で左右に一貫した差があれば**別の暫定方向**を付ける。対立する証拠が得られた場合は保留する。
- 4軸すべての方向が得られた場合にのみ、**「Y/N補完の暫定参考タイプ」**として16タイプの1つを提示する。確定診断や科学的検証済みの分類ではない。
- 全体8問を上限とし、複数軸が不確定なら、まず左右2問を各軸へ配分。最大8問時は4軸の初回ペアが優先され、具体場面質問を行えない場合もある。
- `NO`と`UNSURE`は異なる。全スキップと全4も結果説明・計数で区別する。
- Y/Nの2値得点を7段階の数値へ変換しない。基礎30問のスコア、D243の既存非採点契約は不変。D255の候補絞り込みは**得点とは独立した別層**。
- Y/Nページの回答入力は`YES` / `NO` / `判断できない`の3種類のみ。旧研究版の理由選択プルダウンは画面から除去し、詳細な理由は同意済みの認知面接で確認する。

## 研究上の制限

1. 「YES/NOなら左」「NO/YESなら右」は**設計仮説**であり、独立した二つの価値判断と二極の相対優先を同一視してよいか未検証。B軸などで両者が同時に高い可能性がある。
2. Y/N2問で軸を暫定的に確定すると、30問の7段階採点より証拠が薄い。画面で`Y/N暫定`を明記し、各軸の出所を区別する。
3. 4軸すべて全スキップ後の8問ですべて方向が決まる例を技術的に再現しても、実際の回答者での分類率・再回答安定性・誤分類リスクの実証ではない。
4. Y/Nの上限8問、追加の提示順、具体場面設問の意味の重複は未較正。G1 BLOCKED、G3/G4 AWAITING_DATA、G5 BLOCKED。
5. 自然な実回答0件。合成ケースはアルゴリズムの仕様検証のみ。実施前の認知面接D251〜D252は維持し、人間の回答を創作しない。

## 必須受入テスト

- 全30問スキップ→Y/Nを4軸各2問→左右の片方だけYESなら研究上の暫定1タイプを表示する。
- 全30問4→左右がともにYESまたはNOなら安易に分類せず、残り枠で具体場面を提案する。
- 方向明確な30問→追加質問を出さず従来の参考分類を保持する。
- 30問ではY/N提案基準5/7に満たないが未確定な軸も、D255で追加確認の対象となる。
- Y/N回答前後で、30問の得点・4/skip数・採点対象設問は一切変更しない。
- 31問目以降の追加設問はYES/NO/判断できない以外の尺度を出さない。
- 結果・ブラウザE2E・CI・GitHub Pages実配信一致を確認するまでは公開成功と扱わない。
