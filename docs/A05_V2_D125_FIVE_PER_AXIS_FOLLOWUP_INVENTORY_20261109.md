# A05 D-125｜詳細診断追加質問：各軸5問／計25問の候補洗い出し

**2026-11-09｜編集用質問ドラフト。ユーザー指定の「各軸5問」の数量条件を満たしたため、追加質問候補の洗い出しセクションを完了扱いとする。ただし採点・分岐・心理測定上の妥当性・本番公開を承認したことにはならない。**

## 位置づけ

- 旧A05 v2の共通30問はそのまま。30問の結果、各軸45〜55%または有効回答不足（D-122）に入る場合に、該当軸に限り個別に追加質問する設計。
- D-123で強い意味重複と判定した12問は追加候補から除外し、D-124で残した条件付き候補6問と、新規19問を合わせて**A/B/C/D/E各5問**にした。
- 25問は候補バンクの総数であって、各利用者の回答問数ではない。D125時点ではルータも得点化も未実装。
- 旧問を繰り返すだけでなく、必要性、現状満足、便益の確実性、時間地平、実行機会の再現可能性、未解決課題、時間と金銭の数量など**特定の判断条件**を追加する。ただし条件が追加されれば識別力が向上するとの実証はない。
- Y/Nでの**Noは反対側を支持するとは限らない**。A/B、Y/Nともに「判断できない」「当てはまらない」を選択可能。追加問題を現行7段階へ無校正で合算しない。

## 素案の内容監査で残した主要リスク

- **A**：強制転居、複数拠点、将来の不確実性は「変化が好き」という構成概念と転居可能性やリスク選好が混ざる。A01・A04からの情報増分は認知面接で検証。
- **B**：自分と他者の競合という形式の反復が残る。関係者の種類・希望強度・責任所在で回答が変わり得るため、一貫した固定的な人格類型として解釈しない。特にB-FU12は社会規範・選択肢の非対称性のリスク大。
- **C**：C-FU12/13は3か月/3年の**セット**、C-FU14/15は機会の再現可能性の**セット**。5問は独立した5種類の心理尺度ではなく、条件を対照する質問対を含む。今後、得点化ではなく条件依存の検査専用とする可能性がある。
- **D**：課題未完了/目標達成済/発見が減った/並行学習という4状況を分けた。元D02/D06の再提示に近い箇所が残るため、単独出題による情報増分は未実証。
- **E**：月額増収・勤務時間・家事代行・一時金/休暇・時間帯裁量の5場面にした。具体額はユーザーの収入・負担によって答えが変わる**実験的アンカー**であり、固定レートが妥当とは主張しない。Eは16タイプの構成軸ではない。
