## 目的

研究上B2（本人希望と関係者希望を別々に扱う）を優先しつつ、現行のT01〜T16・136組を**本人の診断タイプと取り違えず**編集上のキャラクター設定として表示するための、R1専用の安全なAPI境界を設ける。

**R1の暫定キャラクター選択は、誰がどのタイプかを心理測定する手続きではない。**

## 実装の入出力契約

- 入力：厳密に `{leftTypeId:"T01",rightTypeId:"T02"}` という2フィールドのみ。T01〜T16以外、診断回答、氏名、関係カテゴリ、B2点数、追加属性は拒否。
- 出力：順序非依存なペアIDとユーザー選択順の左右ラベル、暫定4軸A/B/C/Dの一致・相違、同型の事実。E軸は出さない。
- 同型16組：4軸一致・相違0軸という**構造事実**。好相性・優劣・成功率を意味しない。
- B軸：従来のB1二極ラベルを暫定編集設定と明示し、B2研究優先・B1未検証という警告を常に添付する。
- 安全性：採点、ランク、予測、実回答推定、サーバー送信や端末保存を実装しない。返す値は構造化ラベルと留保のみ。
- ゲート：`publicationApproved:false`、`researchValidated:false`を常に保持。R1実画面との接続はS5/S6/S7/S8通過後に独立判断。
