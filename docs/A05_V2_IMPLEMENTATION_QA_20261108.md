## 数値から導けること／導けないこと

| 数値の条件 | 許される表現 | 禁止する断定 |
|---|---|---|
| 方向保留 | 回答不足または方向の相殺 | 無関心、葛藤、人格的矛盾 |
| 絶対スコア33⅓%以下 | 左右の合計差は小さい | 両方重要、どちらも重要でない、柔軟 |
| 絶対スコア66⅔%以上 | 今回の質問で方向の偏りが大きい | ストレス、譲れない核、適職 |
| P8比較用上位軸 | 今回の相対的な回答の偏りが比較的大きい | 妥協不可、人生最優先、譲歩すべき軸 |

平均・合計だけでは「全回答4」と「3問7＋3問1」を識別できない。現行スナップショットスキーマに`absSum`を追加せず、この限界を開示する。
