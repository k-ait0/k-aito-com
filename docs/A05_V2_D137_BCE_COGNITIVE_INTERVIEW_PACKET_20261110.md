## 0. 面接前の説明（読み上げ案）

「これらの質問は人生で大切にすることを考えるための試作で、正答や優劣はありません。性格や適職を診断するものではありません。途中で答えにくい質問は『判断できない』『該当しない』として飛ばせます。今回は質問がどう理解されるかを確認します。回答は研究用で、16タイプ判定や公開レポートには使いません。」実際に記録を収集する場合は収集目的、保存期間、匿名化、削除方法、任意参加について別途明示し同意を取得。

## 1. デザイン

- 想定：認知面接**8〜12人程度を初期の文言理解テスト用に検討**（統計的妥当性や代表性の根拠にはならない）。多様な生活状況を持つ回答者を候補とするが、必須の個人情報は収集しない。
- 回答順：匿名セッション番号の奇数=相対（二極）→独立、偶数=独立→相対。軸の順番も交互に入れ替えて順序効果を区別する。確率的な割付や推測統計は本段階で行わない。
- 回答形式：二極場面は左右のいずれか、または「選べない」「該当しない」。独立方式は **1まったく重視しない／2あまり重視しない／3どちらともいえない／4やや重視する／5非常に重視する** と「判断できない」「該当する場面がない」を別扱い。
- 1人あたりB3問、C4問、E3問=**計10回答**。全て研究用で非採点。必要ならE02を11問目の追加交絡確認として任意実施。二極の中立回答と欠測を混同しない。
- 同一人の独立2値を差分に変換して既存タイプへ加点しない。`5/5`、`1/1`、`3/3`、`5/4` 等を別々のプロフィールとして記録する。これは**架空例**であり人の分類ではない。

## 2. B軸：相対1問＋独立2問

**相対 B-FU04（原本・研究比較用）**
- 質問：「共同活動の進め方で、成果と負担が同程度の案が二つあり意見が割れた場合、どちらを選びますか？」
- A「自分の納得できる案を優先する」／B「全員が受け入れられる案を優先する」／選べない／該当しない。
- **注意**：「全員が受け入れられる」側に社会的望ましさがあり、二極方式の適切な代表とは**未認定**。

**独立 B-IND-R1**「自分とほかの人の双方に影響する重要な選択では、自分の意向が最終的な選択に反映されることをどの程度重視しますか。」

**独立 B-IND-R2**「自分とほかの人の双方に影響する重要な選択では、関係者が納得できるよう合意を作ることをどの程度重視しますか。」

**確認プローブ**：「他の人とは誰を想定しましたか」「相談することと、最終的な選択を左右することは同じですか」「両方の重視度が高いとき意見衝突が起きたらどう考えますか」。意思決定権・責任・当事者範囲を記録する。

## 3. C軸：条件対照相対2問＋独立2問

**相対 C-FU14（両方とも今週しか選べない条件）**
- 質問：「将来に役立つ準備も、現在を楽しむ体験も、どちらも今週しか選べない機会だとします。同じ時間ならどちらを選びますか？」
- A「今週限りの将来の準備機会を選ぶ」／B「今週限りの現在の体験を選ぶ」／選べない／該当しない。

**相対 C-FU15（両方とも来週にもできる条件）**
- 質問：「将来の準備も、現在を楽しむ体験も、今週選ばなくても来週同じように実行できるとします。同じ時間なら今週はどちらを選びますか？」
- A「来週にもできる将来の準備を先にする」／B「来週にもできる現在の体験を先にする」／選べない／該当しない。
- 2問の回答差が生じても時間的選好だけに帰属しない。利益量・関心・目標などを自由回答で聞き取る。

**独立 C-IND-R1**「自分で使い道を決められる余力があるとき、将来の目標や選択肢のために準備することをどの程度重視しますか。」

**独立 C-IND-R2**「自分で使い道を決められる余力があるとき、今行う活動それ自体の充実感をどの程度重視しますか。」

**確認プローブ**：「将来の準備とは何を想定しましたか」「目標が明確でない人でも回答できますか」「今の充実は休息、趣味、達成感のどれを想定しましたか」「2つの相対問で条件が変わると理由が変わりますか」。

## 4. E軸：相対1問＋独立2問

**相対 E01（原本・保留中、交絡を確認するためだけの比較用）**
- 質問：「次の二つのあり方では、どちらを優先しますか？」
- A「収入を増やせる働き方」／B「自由な時間を確保できる働き方」／選べない／該当しない。
- E01は増える収入と時間の数量が不明で就労前提、**良い二極設問との基準比較ではない**。回答不能は記録し、無理に回答を誘導しない。

**独立 E-IND-R1**「日々の生活で、必要な支出を賄ったうえで自分の判断で使えるお金の余裕を持つことをどの程度重視しますか。」

**独立 E-IND-R2**「日々の生活で、必要な用事や休息を満たしたうえで自分の判断で使える時間の余裕を持つことをどの程度重視しますか。」

**確認プローブ**：「『必要な支出』や『十分な時間』を何で判断しましたか」「現状の所得、仕事の有無、体調や家族の義務で回答が変わりますか」。具体的な給与額・資産額等の個人情報は尋ねない。

## 5. 共通の回答後プローブ

1. **復唱**：どのような選択を聞かれた質問だと理解したかを自分の言葉で説明してもらう。
2. **前提**：どの場面や人を想像したか。質問文が指定しない条件を自分で補ったか。
3. **迷い**：左右が同時に成立して答えにくいか、価値と現実制約を取り違えたか。
4. **形式差**：二極の選択と独立評価が異なって見える理由をどう理解するか。
5. **非該当**：回答不能と「どちらも重要でない」を区別できたか。
6. **誘導**：より立派・合理的に聞こえる選択肢はあったか。
