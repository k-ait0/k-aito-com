## 意味づけと禁止事項

- **案L**：従来に近い生活環境・関係性の概念。**案M**：活動方法・意思決定の概念。**案R**：人生選択の優先基準を広く捉える再設計の仮説。
- 案Rを優先して比較することは正式採用でも実測上の優位性でもない。B軸の両極が共存し得る問題、A軸とD軸の混入などが残る。
- A04・A05・B02のBLOCKは解除しない。C04・D03・E04・E05も別台帳でBLOCKのまま。
- 研究の実施はG1の12決裁、D-42の受入確認、実責任者、保管先、保存期間・同意・撤回・削除の運用承認が必要。許可前に参加者へ画面を配布し回答させない。
- Draft PR #61への技術的な追加だけであり、診断`questions.mjs`や`engine.mjs`に候補文面を反映しない。公開、マージ、無断での実回答調査、旧結果の変換を行わない。
