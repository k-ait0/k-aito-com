- 10ページレポートP3〜P5でスコアの観測範囲により4段階の**記述強度**を調整する。高い絶対スコアでも「ストレスを感じる」「譲れない核」「心理的に確定」とは断定しない。
- P7は有効回答4以上で**数値の絶対値が小さい2軸**を注視。低い絶対値は回答の相殺・中立・未回答など複数原因を含み、`葛藤`／`両方大事`／`柔軟性`を推定できない。対象者自身に確かめる問いとして表示。
- P8は有効回答4以上の2軸（絶対値が比較的大きい）を「今回の回答で相対的な方向が表れた軸」として紹介。**妥協不可条件や優先順位そのものは推論しない**。低スコアを譲歩の推奨に使わない。
- P9はW1で上位軸の現状満足度を自分で評価、W2で低スコア軸の別側を**安全で負担のない範囲**で試すか考える。W3はタイプに設定された行動案、W4は振り返りを維持。
- E軸：働き方／余暇／節約・時短／報酬・負荷／生活スタイル／安心感を分離。ただし、消費・不安・健康・仕事制約と時間の自由が混ざる危険は残る。生活環境によらず公平に測れると主張しない。
- A軸は住環境、日常空間、コミュニティ、生活リズム、活動環境、ホーム/アウェーを扱うが、B軸（人間関係）やC軸（時間）の概念が混入していないか確認する。
- B・C軸の二者択一問題は、相対選好を具体化しても完全には解消しない。「両方大事」と「どちらも興味ない」は同じ中点に集まり得るため、認知インタビューで確認する。

## 適用判断とテスト

1. **PR #75**：研究JSONと本書のみ。レビュー後マージしても公開実行ファイルには影響しない。
2. **別Draft PR**：質問／採点／レポートの改修コードとテスト。公開中mainとは分離し、旧v1のバイト同一性を保持。
3. **ローカル / CIゲート**：質問30問・固定方向・SHA-256、閾値 `n=6,sum=6` → provisional、`n=6,sum=7` → classified、`n=6,sum=0` → withheld、16タイプ×E軸、レポート全10ページ／プライバシー／HTMLサニタイズ、v1旧履歴の legacy と再採点なし。
4. **回帰注意**：旧版のスコア・分類の期待値を単に全面更新して旧版の結果を消さない。v1データをレガシーとして保存したままv2を検証する。UI / IndexedDBを変えない要件では、v1の履歴閲覧に機能的制約が残る場合は**マージを保留**する。
5. **人的検証**：5〜8名程度の認知インタビューは初期の定性的目安であり、統計的妥当性・信頼性の根拠とは扱わない。回答不能条件、選択文の魅力度、重複、各軸の解釈を具体的に記録する。
6. **PDFレイアウト**：既存の `report.css` には印刷時の `@page{size:A4;margin:0}` と `print-color-adjust:exact` があるため、追加の`@page margin:10mm`、`max-height/overflow:hidden` は**追加しない**。クリッピング／余分なページを招くため。

## リスクと進行条件

- **誤認リスク**：「バランス」「葛藤」「譲れない」「ストレス」といった心理解釈は、この集計値単体で判断できない。
- **データリスク**：旧版の回答構造を保持する一方、`classifySnapshot`の旧版処理と保存同意・データ消去の境界を明示的に検証。
- **技術リスク**：UIがv2と旧版履歴をどう表示するか、ブラウザE2Eと実PDFが本番相当の条件で合格するまで本番反映なし。
- **公開判定**：研究用候補は「設計確定」であって心理測定の実証完了ではない。公開版v1の動作と記録を優先。
