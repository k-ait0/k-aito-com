# A05 D-139｜B/C/E二極・独立の比較用オフライン画面とQA

**2026-11-10／非採点の研究用試作。本番／既存ランタイム未変更。** [HTML](../research/a05/d139-bce-unscored-comparison-offline.html) はD-137の研究用10設問（B3、C4、E3）を単一HTMLで回答できる試作。D-135の独立6問と既存二極4問を対照し、タイプ判定には用いない。

## 仕様
- 10問表示。B-FU04、B-IND-R1/R2、C-FU14/15、C-IND-R1/R2、E01、E-IND-R1/R2。
- 二極は左／右、判断不能、非該当。独立5件法は1〜5、判断不能、非該当。中央3を欠測に置換しない。
- 研究用表示順「二極→独立」／「独立→二極」を切替え可能。切替時は旧回答を消去して順序と回答の取り違えを防ぐ。
- 生回答のJSONを**利用者の明示操作時だけ端末に書き出す**。未回答はnullで保持。過去履歴の保存、サーバー送信、外部ライブラリ・アクセス解析は実装していない。
- 独立評定値の差、均衡フラグ、診断結果、16タイプ、心理測定上の尺度得点を計算しない。
- v1本番およびPR #76の質問BANK、採点、レポート、履歴を変更せず、研究用HTMLを単独追加した。

## 実行済みQA（この作業環境のLinux Chromium 144）

1. 10個の設問を表示し、研究用IDが正しく現れること。
2. 初期表示順と逆順グループで設問順が切り替わること。
3. 形式切替時の回答消去、回答進捗の再計算が正しいこと。
4. 全10問に仮回答後、JSONをダウンロードし10件のraw answer、B=3、C=4、E=3、判定未実施フラグを確認したこと。
5. 回答消去後に0/10に復帰すること。
6. 390pxモバイル幅で10問を表示し、横スクロールが発生しないこと。
7. JavaScript例外0、外部ネットワークリクエスト0、ブラウザ保存API不使用を確認したこと。

**結果：上記7群のチェックはすべてPASS**。Playwrightが一時的なHTML読込を使ったブラウザテストであり、iOS Safariや本番公開環境のQAを実施したものではない。研究用の設問内容の妥当性は検証していない。
