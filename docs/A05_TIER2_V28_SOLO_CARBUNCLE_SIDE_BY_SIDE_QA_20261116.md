## v28での実成果
1. **カーバンクル（CC-00、変化×つながり）を独立した単体縦長画像として生成**。1086×1448px。v27までの2分割画像からの切り出しという制約を解消。額の青い宝石・両耳・尾・足・背景を画面内に収めた。画像に文字・UI・RGBY・スコアは描画しない。
2. **ペガサス（CA-11、変化×自律）はv27単体画像を維持**。1086×1448px。以前の翼端欠け・四肢の見切れを改善済みで、今回あえて再生成していない。
3. 2枚の独立原画の比較と、カーバンクルv27旧切り出し⇄v28独立原画の差分確認ができる**ローカルレビューHTML v28**を作成。手動のRGBY枠線4色、E軸 `money` / `time` / `none`、デスクトップ/スマホ幅を切替可能。
4. PNG3件、レビューHTML、SHA-256付マニフェスト、README、ブラウザQA JSON・スクリーンショット3件を**会話内の A05_Tier2_v28_Review_Kit.zip**として納品。**この画像・HTML・ZIP自体はGitHubにアップロードしておらず、GitHubでは本レポートのみ管理**。
5. 正式Tier2美術承認は**0/16**。試作候補は2/16。Tier1は16/16初稿・静的構造確認済みだが、24pxの人による視認性判定は未実施。

## v28の独立表示テスト

- ブラウザ：Chromium、Playwright。
- ローカルHTMLのファイルURLでは画像取得が制限されたため、**テスト時に限り3画像をdata URIへ置換して `page.set_content()`でロード**。このテストを実サイトA05のE2Eや、ZIP展開後のブラウザ直接読込と同一視しない。
- 320・390・768・1280pxの全4幅で、2枚の画像デコード、旧v27切り出し画像への切替およびv28への復帰、CSSのR枠線 `rgb(255,59,92)`、E軸「時間的自由」表示、JavaScript例外ゼロ、横はみ出しゼロを検証し**4/4 PASS**。
- PNGは両独立画像とも1086×1448、v27カーバンクル切り出しは757×1024。ZIP全ファイルのCRC整合確認済み。
- レビュー画面は `object-fit:contain` を使い、UI側で翼端や尾を強制的に切り抜かない。
