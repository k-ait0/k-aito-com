## 4. 人間の先行面接を進める最短手順

1. 端末で`preview/yn/`を開き、本人が**自然に**30問を回答。Y/Nを出すために4/スキップを強制しない。担当者は時間・混乱・中断を記録し、質問の意味を回答中に教えない。
2. 結果画面について、まず本人の言葉で説明を求める。自然回答でY/Nが**表示されたか**を`OFFERED` / `NOT_OFFERED` / `NOT_OBSERVABLE`として記録。
3. `OFFERED`なら本人が希望した場合だけ実画面でY/Nを進め、独立した左右・NOとUNSURE・理由・任意性・中断可能性を確認する。途中終了は失敗と扱わず理由を記録。
4. `NOT_OFFERED`なら、希望者に限りカード理解トラックCを実施。原文はD243の該当軸の左右2問。**自然回答トラックNの画面内Y/N出現率・完走率へ加算しない。**
5. 最後に「難しかった言葉」「中間やスキップを選んだ理由」「重複に感じた箇所」「終了したくなった箇所」を自由に聞く。要約だけを最小限匿名化して残す。
6. 1人ごとに匿名観察票を閉じる。実際の人間の回答が2〜3件揃うか、重大な理解・倫理上の問題が発見された時点で先行パイロットをレビュー。人工データで欠員を埋めない。
