## 数理的な採点ストレステスト（実ユーザー調査ではない）
- 1軸6問・1〜7の全`7^6=117649`通りを同じ重みで列挙。v2の`sum=0`→withheld、`1<=|sum|<=6`→provisional、`|sum|>=7`→classified。
- withheld **9,331（7.93%）**、provisional **86,086（73.17%）**、classified **22,232（18.90%）**。これは一様な仮想回答の数理分布であり、利用者の実際の割合を予測しない。
- 有効範囲内で単一回答を1段階だけ変更できる全隣接ケースを列挙したところ、**約16.15%** で「方向あり／保留」が切り替わり、**約23.06%** でclassified/provisional/withheldの状態が切り替わった。反対極への一度の反転を意味しない。
- 特に`n=6,sum=1`でも方向が付いて16タイプのビット計算に使われる（表示は暫定）。**暫定タイプを利用者が確定的な人格類型と誤認しないか**、境界での再検査安定性とUIの双方を確認する。
