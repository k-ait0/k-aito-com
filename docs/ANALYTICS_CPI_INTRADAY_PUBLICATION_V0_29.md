# Analytics v0.29 — 日本CPIの公表日時・基準改定のイベント監査

2026-11-13 JST、自己研究専用。v0.28ブランチから継承し、本番、main、DWZ PR #70には反映しない。

## 実際に一次資料で確認した事項

- 2025年基準遡及改定および接続指数は **2026年8月7日 16:00 JST** に別イベントとして公表。e-Stat統計公表予定 https://www.e-stat.go.jp/release-calendar/statistics/00200573 および総務省 https://www.stat.go.jp/data/cpi/2025/sokyu.html
- 2026年7月全国総合は **2026年8月21日 08:30 JST**、総合指数102.0。e-Stat dataset `000040491312` および当時の総務省統計局ページ https://www.stat.go.jp/data/cpi/sokuhou/tsuki/index-z.html?mod=article_inline
- 2026年8月全国総合は **2026年9月18日 08:30 JST**、総合指数102.2。e-Stat dataset `000040501408` の公開年月日時分、当時の月報内容による。
- 2026年9月全国総合は **2026年10月23日 08:30 JST**、総合指数102.2。e-Stat dataset `000040513537` / https://www.stat.go.jp/data/cpi/sokuhou/tsuki/index-z.htm と統計局の原則公表時刻 https://www.stat.go.jp/data/cpi/4-1.htm による。
- 小数第3位の**参考値**が、 https://www.stat.go.jp/data/cpi/2025/sokyu.html の `https://www.stat.go.jp/data/cpi/2025/csv/zmi2025aa.csv` にある。公式指数および変化率は小数第1位であり、この3桁値は精度を保証するものではなく参考値。サイトは年月ごとに更新される可能性があり、現在のCSVを過去の公表版と称さない。

## 修正前の弱点

v0.28 は日付しか入力せず「公表翌日から利用可能」という保守的規則を採用。金融市場の時刻付きモデルにそのまま適用すると、当日 08:30 頃と当日終了時点の情報を同一扱いできない。v0.26 も、**基準改定は通常月報と異なる公表時刻**であることを明示していない。

## v0.29 追加仕様

`ANALYTICS_CPI_OFFICIAL_INTRADAY_V029.json` は基準改定イベント1件と通常全国月報3件（計4件）の公開日時・出典・丸められた指数をレビュー済みカタログとして固定。月報の3件はv0.28の確認済み記録と一致しなければ拒否。時刻はJSTオフセット+09:00のみ受入。

- `--asof-jst 2026-08-07T15:59:59+09:00`：基準改定の存在も未公表。
- `--asof-jst 2026-08-07T16:00:01+09:00`：基準改定は公表済み。ただし遡及値の原本は未取得なので数値利用不可。
- `--asof-jst 2026-08-21T08:29:59+09:00`：7月月報はまだ利用不可。
- `--asof-jst 2026-08-21T08:30:01+09:00`：7月月報の確認済み丸め指数102.0は参照可能。
- `--asof-jst 2026-09-18T08:30:01+09:00`：8月月報の丸め指数102.2を参照可能。
- `--asof-jst 2026-10-23T08:30:01+09:00`：9月月報の丸め指数102.2を参照可能。

公表秒と同じ時刻は**安全側で不可**とする。「公表予定日時」は観測された配信完了時刻の記録ではないため、この実装はミリ秒単位の可用性を保証しない。

## オフライン利用

```powershell
node scripts/check-analytics-cpi-intraday-v29.cjs --asof-jst '2026-09-18T08:30:01+09:00'
node scripts/check-analytics-cpi-intraday-v29.cjs --local-pdf 'C:\\AnalyticsPrivate\\cpi-2026-08.pdf'
```

`--local-pdf` は利用者が取得した候補PDFのヘッダ・終端・サイズを検査し、SHA-256だけ報告する。元の取得URL、出典時点の記録・公表版との一致の認証は**行わない**。PDF本文や秘密鍵を出力・送信・GitHub配置しない。SHA固定のためにはユーザー非公開フォルダーで原本との照合が別途必要。

## 制約と続く最短工程

- 当環境から `e-stat.go.jp` や `stat.go.jp` のバイナリ原本を直接ダウンロードできず、原本SHA固定と2週間超の実値公表版構築は**未実施**。
- PDFの原本判定、CSVのデータ精度・連続性・改訂有無は未認証。参照ページには見られてもその時点の全指数が保存されているとは限らない。
- 2025年基準の遡及値は2026-08-07より前の意思決定に使わない。基準年をまたぐときは同一時点に実在した版だけを正しく使用。
- v0.29のテーブルは公式の小数第1位丸め指数の**参考表示のみ**であり、円建て正式バックテスト用の `OBSERVED_RESEARCH` 系列に昇格させない。
- 公的な一次資料・元CSV・PDFをユーザーPCで取得し、取得ファイルそのものを安全に保管してSHA固定→各資料の発行年月、版、連続性を審査→実原本QAに接続する。

本番・main・Draft DWZ PR #70には変更なし。
