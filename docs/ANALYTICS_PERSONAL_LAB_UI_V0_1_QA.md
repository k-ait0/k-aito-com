# K. Aito Analytics｜Personal Lab v0.1 — 本人専用ブラウザー版（2026-11-11）

**status: PERSONAL_LOCAL_BROWSER_UI_IMPLEMENTED / OFFLINE_CSV_VALIDATED / MAIN_AND_PUBLIC_SITE_UNCHANGED**

## 目的と配布形態

ローカルのHTMLを直接開いて操作できる**単一ファイル**の自己利用用研究アプリ。外部ライブラリ・API・CDN・保存サーバー・Cookie・localStorageを使わない。CSPは default-src/connect-src/object-src を none に設定する。原本CSVはブラウザー内のFile APIで読み込み、メモリ内で処理する。読込データをGitHubやWebへアップロードしない。ブラウザーのファイルダウンロード操作で生成した**派生結果だけ**をユーザーが明示保存できる。

コード：research/analytics/personal-lab/index.html

### 操作方法

1. 上記index.htmlを保存してChrome/Edge/Safari等のブラウザーで開く。標準は**合成デモ**であり、実績ではない。まず簡易・詳細、購買力分析・取り崩し試算を操作する。
2. 実データを使う場合、左側「実CSVを使う」から、次の2つを端末上のファイル選択で指定する。
   - FX：Kaito_Analytics_Fed_H10_USDJPY_1971_2026_RESEARCH_CANDIDATE_PRIVATE.csv
   - 日本CPI：Kaito_Analytics_JP_CPI_2025base_CANONICAL_OBSERVED_PRIVATE.csv
3. 端末内で読み込むを押す。670か月のFXと681か月の全国総合CPIは共通669か月（1971-01〜2026-09）に揃う。原値そのものは画面のHTMLに保存されない。
4. 「購買力分析」で米ドル現金（**利息なし**）、円現金（利息なし）、名目・実質を比較。詳細モードでは10/20/30年の連続観測開始月全数に対する倍率の最小/中央値/最大・1倍超の開始月割合を表示。
5. 「取り崩し試算」で初期資金、月額、名目固定/日本CPI連動、歴史的開始月、10/20/30年を設定。実際の月次価格変化を用いて、月末引き出し後の残高と歴史的開始月ごとの完走数を計算。取り崩し不能後は残高0を維持。
6. 「結果CSV保存」で月次の計算結果を本人が端末に保存する。
7. 金を使う場合のみ次の隔離研究ファイルを明示選択し、警告にチェックする：
   - Kaito_Analytics_WorldBank_Gold_PUBLISHED_UNVERIFIED_QUARANTINE_20261111.csv
   - 金は**公表値だが各月の実測・予測を分離できていない**こと、2025年6月の参照価格定義変更、現物価格が投資可能TRではないことを表示。正式OBSERVEDデータとして扱わない。

## 計算式

USD現金購買力（開始月=100）:
100 × (USDJPY_t / USDJPY_0) × (JP_CPI_0 / JP_CPI_t)

円現金購買力:
100 × (JP_CPI_0 / JP_CPI_t)

金の探索値（未検証公表水準）:
100 × (Gold_USD_t / Gold_USD_0) × (USDJPY_t / USDJPY_0) × (JP_CPI_0 / JP_CPI_t)

取り崩し：開始月の保有額を円建て初期資金とし、当月/前月の市場価値水準比を掛けてから引出しを行う。実質固定を選んだ場合は初月引出額に CPI_t/CPI_start を乗ずる。引出額上限はその月の保有額、負の残高・借入・追加投資は不可。

10/20/30年の開始月数：連続する361か月の水準があれば30年の月次変化360本を計算できる。比率は**互いに重複する歴史的な観測窓の実績**であり、将来の予測成功確率ではない。

**注意**：USDには金利を付与しない。FX換金費用、金保管・取引費用、税、銘柄配当、先物ロール等を含まない。商品・株式TRシミュレーターの代替として解釈してはならない。

## QAと保護

- Node単体（ファイル外部依存なし）：scripts/test-analytics-personal-ui.cjs
- Chromium headless（個別ランタイムで実施）：合成デモ、簡易/詳細、購買力、取り崩し、実ファイル読込、金のチェック必須、モバイル表示、コンソール例外、ネットワーク接続要求ゼロを確認。
- 実ファイルとの独立整合：USD cash、JP CPI、1971-01〜2026-09の669か月。開始指数100、終了指数**12.387652785974575**。従来のPython実データQAレポート 12.387653 と一致。30年水準変化の完走開始月309。
- CSVを読み込む際、系列ID、origin、series_kind、出典、単位、通貨、64桁SHA、日付、重複・連続性を拒否条件として検査。Goldは PUBLISHED_LEVEL_STATUS_UNVERIFIED に限る。
- UIには元CSV行データをハードコードしていない。GitHubリポジトリには**合成デモ、検証コード、注意事項のみ**記録。
- 利用端末ブラウザーでの直接HTML表示に未対応の場合は、ローカルだけで動かすHTTPサーバー（127.0.0.1）で表示する。公開ホストではデータをアップロードしない。
- HTMLとJSは単一ファイルで、ネットワーク要求・外部埋込を使わない。ただしPC自身のマルウェア・ブラウザー拡張・共有画面等への情報露出はこのアプリ単体では防げない。

## 残る機能と開発上の境界

**実装済み**：簡易/詳細切替、ローカルファイルCSV読込、購買力・為替・CPI・探索金、ローリング期間比較、決定論的毎月取り崩し、CSV保存、注意事項、オフラインUI。

**未実装**：実際の配当込み株式TR・債券TR・REIT TRの網羅、複数資産のリバランスやポートフォリオ最適化、税・手数料・信用取引・資産配分の変更、乱数シミュレーション、過去のDWZ全エンジンへの接続。適法に取得した個人用TRインデックスの追加は別フェーズ。

**本番未実施**：mainマージ、FINOWA掲載、公開K. Aito Analyticsへのデプロイ、ユーザー認証・クラウド共有、商用配信ライセンス承認、Fed 1971 DDPソースADRの正式採用。
