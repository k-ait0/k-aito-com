## 3. 採点仕様の内容

研究用の各回答得点：
`s(x) = sign(x-4) * (abs(x-4)/3)^1.5`。

- 1〜7の極端さを相対的に強調する。主軸の質問は同一係数、複数軸への副次加点なし。
- 回答の方向を軸で平均し、`abs(mean) <= (1/3)^1.5` を弱い（WEAK）とする暫定参照閾値。
- 有効回答5未満または4つの異なる意味グループ未満ならINSUFFICIENT。
- 合計ほぼ0ならTIE。
- 1問除外、または1意味グループ除外で符号が消える・反転する場合をFRAGILE。
- これらを通過した軸のみ「DIRECTIONAL」に分類する。これは**頑健性のルール**であって統計的な確信度ではない。
- 4軸の未確定方向は両側を残し、16タイプ候補集合を計算。候補1/2〜4/8〜16に区別する。
- 追加質問は未確定の軸へ、まだ出題していない意味グループを優先して2問ずつ追加。最大2回、34問まで。
- 全項目とも研究用であり、上記分類に`scoreValid:false`を明示する。

## 4. 残る問題・悲観的レビュー

### P0：科学的な較正と内容上の前提が未確定

- `(1/3)^1.5` は説明可能な**便宜上の目安**であって、正答率、再受検一致率、信頼区間などから求めたものではない。
- 「中間＝4」で両方重視・両方重視しない・状況次第を区別できない。B/C軸の構成概念が未閉鎖。
- C31・C32・C36を除外しても、残りの設問が独立・適格と確認されたわけではない。
- 「強い回答ほど正確」という仮定は未証明。1.5乗を採用候補とした判断は、人工回答のロバストネス上の折衷案である。

### P1：追加質問は「出題不足の補充」であり情報利得の最適化ではない

- 未出題の意味グループが少ない順に選んでいるが、問題を増やした際に実際に判定精度がどれだけ上がるかは計算していない。
- 7問から9問へ増やすときの軸比較・集計への影響は構造上扱えるが、正規化後の較正が必要。
- 回答によって追加入力が偏るため、一般的な30問固定セットと混ぜて「同じ尺度の結果」とは見なさない。

### P1：技術的な検証の限界

- 823,543件は「得点の左右対称性と範囲」の**組合せ列挙**であり、823,543人の採点や全質問の意味検査ではない。
- 250,000件の人工回答は作成した10パターンに依存。独立した参照実装・人間回答との照合が残る。
- 入力のID・軸・出題数は検査しているが、**宣言されたseedと元D224抽出セットが完全に一致するかの真正性検証**は未実装。研究用manifestの改ざん防止には追加ガードが必要。
- CIレポートの違反件数0のフィールドは、実行中に不変条件違反があれば例外でジョブを停止させる方式に基づく。別途エラー種別別の収集試験はない。

## 5. 次に修正する優先順位

1. **P1／技術ガード**：manifest再現検証（seed・30問ベース、任意追記履歴）と独立参照計算で、技術的な入力真正性を高める。
2. **P0／測定内容**：C36差し替え候補、B/C同時高低の回答形式、18組の意味的重複に人間レビューを付ける。
3. **P0／較正**：同意のある実回答で1.5乗 vs 線形の安定性、境界閾値、保留率と追加入力効率を事前指標によって検証する。
4. **判定**：修正した根拠ごとにUI抜きで80点再査定。自動テストの件数だけでは点数を上げない。
