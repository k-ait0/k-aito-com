海の上で工場を動かしたらどうなる？
――原子力加工船という妄想

「なんで誰もやってないんだろう？」から始まって、気づけば原子力船、海上工場、往復物流、銅精鉱と硫酸、油脂の循環まで調べていた。

これは事業計画ではなく、思考実験です。

「こんなのあったら面白くない？」から始まった妄想に、現実の物流・技術・制度を混ぜながら、どこまで筋が通るのか考えてみました。

先に流れだけ見るなら、ここでだいたい分かります。

きっかけは「海の上で加工したら税金も変わる？」だった

最初は、もっと単純だった。海外で原料を買って、日本へ運ぶ途中の公海上で加工する。そうすると「どこの国で加工したことになるんだ？」と疑問に思った。さらに、税金や関税の扱いも何か変わるのでは、と。

ただ、公海は「法律も税金も存在しない場所」ではないし、船には旗国の管轄がある。日本へ輸入すれば輸入時の評価や原産地なども問題になる。単純な「海上加工＝節税装置」ではなさそうだった。

でも、税金より「輸送中に加工できること自体」の方が面白くないか？

「輸送時間」をそのまま「加工時間」にできないか

普通なら、原料を積んで何週間も海上輸送し、日本で荷揚げしてから工場へ運び、そこで初めて加工が始まる。

原料を積む→20日輸送→荷揚げ→工場で加工

でも船の中に加工設備があれば、こう変えられる。

原料を積む→20日間、移動しながら加工→到着時には半製品・製品

輸送と加工を直列でやるのではなく、並列化する。 船を「物を運ぶ箱」ではなく、移動中も価値を増やす設備として見る。

原子力なら「船を動かす」以外にも使える

原子炉が作るエネルギーを、推進だけでなく船内電力やポンプ、圧縮機、蒸気、プロセス熱へ配分することも考えられる。

推進船を動かす
電力ポンプ・圧縮機など
プロセス熱加熱・蒸気・反応工程

もちろん「発電後に捨てる高温熱が全部タダで使える」という話ではない。高い温度の熱を加工へ回せば、その分は発電や推進との配分になる。それでも、1つの原子炉を船＋発電所＋工場のエネルギー源として共用するという構造にはできる。

「原子力船に工場を載せる」より、「原子力工場に移動能力を持たせる」と考えた方が近い。

そもそも「海上工場」はすでに存在していた

海上で巨大な加工設備を動かすこと自体はSFではない。ShellのPrelude FLNGでは、天然ガスを海上で処理・液化・貯蔵し、LNG船へ積み替えている。

Preludeは航海しながら加工する船ではなく、海上に係留して使う設備だ。それでも「工場は陸上に置かなければならない」という前提はすでに崩れている。

片道だけ加工すると、設備が遊ぶ

ここでかなり現実的な問題にぶつかった。帰りの航海でしか加工しないなら、往路では高価な加工設備が休む。原子炉も加工設備も高いのに、半分の時間しか使わないのはもったいない。

そこで次に考えたのが、往路と復路の両方で加工できないか？だった。

実際にあった「日本→チリは硫酸、チリ→日本は銅精鉱」

調べると、かなり都合のいい実例が見つかった。日本マリンは、日本―チリ間で往航に硫酸、復航に銅精鉱を運ぶ特殊船を実際に運航している。

チリで銅精鉱を積む↓日本へ航海しながら乾燥・一部処理↓硫黄分を含む工程からガスを回収↓硫酸製造まで組み合わせる↓次の日本→チリ便で硫酸を運ぶ

実際の製錬工程や環境設備をそのまま船へ載せられるわけではない。それでも面白いのは、存在しない物流をゼロから作る必要がないことだ。すでにある往復物流へ加工工程を差し込めないか、という話になる。

もう一つ相性が良さそうなのが「油⇄油」

銅精鉱と硫酸は面白いが、固体鉱物と液体酸では必要設備がかなり違う。「往復で同じ設備を使う」という視点では、油の方がきれいかもしれない。

日本 → 東南アジア

廃食油・廃油 → 脱水 → ろ過 → 前処理 → 必要なら水素化

東南アジア → 日本

植物油 → 脱ガム → 脱酸 → 脱臭 → 分別

どちらも液体だから、タンク、ポンプ、配管、熱交換器、蒸気系、真空系、一部の反応設備を共用しやすい。加工船では、何を加工できるか以上に「同じ設備を往復で使えるか」が重要なのかもしれない。

逆に「船で加工しない方がいい原料」もある

例えば水分が多く、乾燥すると重量が大きく減る原料なら、原産地で乾燥してから積んだ方が合理的な場合が多い。大量の尾鉱や残渣が出る鉱石も同じだ。

そういうものは航海する加工船より、資源産地の沖に浮かべた固定式の海上工場の方が向くかもしれない。

大事なのは、「船で加工できるか」ではなく「移動しながら加工する理由があるか」。

原子力船なのに、速すぎても困るという矛盾

加工船では、航海時間そのものが加工時間になる。10万トンを20日で処理するなら1日5,000トンだが、10日で着けば1日1万トンの加工設備が必要になる。

つまり、速い船ほど良いとは限らない。船速、原子炉出力、加工能力、航路、荷役時間をまとめて最適化する必要がある。単なる造船ではなく、物流システム全体の設計になってくる。

一番大きい壁は、たぶん技術だけではない

原子炉、加工設備、タンク、安全設備、遮蔽、防爆、排水処理、残渣処理、荷役設備を1隻へ載せるだけでも大事業だ。さらに原子力規制、海事規制、国際ルール、保険、事故時の責任、港湾の受け入れまで必要になる。

IMOでは現在、原子力船に関するNuclear CodeとSOLAS Chapter VIIIの改訂作業が進んでいる。2026年1月のSDC 12で示された工程では、2030年に改訂コードと関連改正をまとめる計画になっている。

それでも、この妄想は結構好きだ

最初は「公海で加工したら税金的に面白いんじゃない？」という雑な疑問だった。

税金 → 原子力船 → プロセス熱 → 海上工場 → 輸送中加工 → 往復加工 → 移動する原子力コンビナート

最後に残ったのは、輸送という「何も作っていない時間」を、価値を作る時間に変えられないか？という問いだった。

固定工場の方が安いかもしれない。規制で行き詰まるかもしれない。加工に向く貨物がほとんど見つからないかもしれない。

でも「船は運ぶもの」「工場は陸にあるもの」という前提を一度外してみるだけで、結構違う世界が見える。こういう、調べれば調べるほど完全な妄想とも言い切れなくなってくる話は面白い。

もし数十年後、本当に世界の海を走りながら原料を加工する巨大工場船が現れたら、「あれ、昔こんなこと考えたな」と思い出したい。それくらいの温度感で、このメモを残しておく。

この妄想の要点

  • 輸送時間を加工時間に変える
  • 原子炉を推進・電力・プロセス熱で共用する
  • 片道ではなく往復で加工設備を動かす
  • 既存の往復物流に加工工程を差し込む
  • 固定工場より船上加工が有利な品目だけを狙う
  • 「船」より「移動可能な海上コンビナート」と考える
